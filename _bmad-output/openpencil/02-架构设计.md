# OpenPencil 架构设计

## 设计原则

### 1. 模块化优先
- 每个模块独立开发、测试、部署
- 清晰的接口定义
- 最小化模块间依赖

### 2. 开源友好
- 使用主流开源技术栈
- 清晰的代码结构
- 完善的文档和示例

### 3. 渐进式实现
- 先实现核心功能
- 逐步添加高级特性
- 保持向后兼容

### 4. 可扩展性
- 插件系统 (计划中)
- 自定义渲染器
- 可配置的工具链

## 核心模块设计

### 1. 类型系统模块 (Types)

#### 职责
- 定义所有数据结构的 TypeScript 类型
- 提供类型安全保障
- 文档化数据模型

#### 核心类型

```typescript
// 文档结构
interface PencilDocument {
  version: string;
  metadata: DocumentMetadata;
  canvas: CanvasConfig;
  layers: Layer[];
}

// 图层结构
interface Layer {
  id: string;
  type: 'shape';
  name: string;
  visible: boolean;
  locked: boolean;
  opacity: number;
  shape: Shape;
}

// 图形联合类型
type Shape = 
  | RectangleShape 
  | CircleShape 
  | EllipseShape 
  | LineShape 
  | PolylineShape;
```

#### 文件组织
```
types/
├── index.ts        # 统一导出
├── document.ts     # 文档类型
├── layer.ts        # 图层类型
└── shape.ts        # 图形类型
```

### 2. 格式处理模块 (Format)

#### 职责
- .pen 文件的解析和序列化
- 数据验证
- 版本迁移 (计划中)

#### 核心类

**PencilParser**
```typescript
class PencilParser {
  parse(jsonString: string): PencilDocument;
  serialize(doc: PencilDocument): string;
}
```

**验证器**
```typescript
function validateDocument(data: any): ValidationResult;
function validateShape(shape: any, layerIndex: number): string[];
```

#### 验证规则
- 必需字段检查
- 类型检查
- 数值范围验证
- 图形特定验证

#### 文件组织
```
format/
├── index.ts        # 统一导出
├── parser.ts       # 解析器
└── validator.ts    # 验证器
```

### 3. 渲染引擎模块 (Renderer)

#### 职责
- Canvas 2D 渲染
- 图层管理
- 性能优化

#### 核心类

**CanvasRenderer**
```typescript
class CanvasRenderer {
  constructor(canvas: HTMLCanvasElement);
  render(document: PencilDocument): void;
  private clear(canvas: CanvasConfig): void;
  private renderBackground(canvas: CanvasConfig): void;
  private renderLayer(layer: Layer): void;
}
```

#### 渲染流程
```
render() 
  → clear()           // 清空画布
  → renderBackground() // 渲染背景
  → for each layer:
      → check visible
      → renderLayer()  // 渲染图层
```

#### 图形渲染器
每种图形类型有独立的渲染函数:
- `renderRectangle()` - 矩形渲染
- `renderCircle()` - 圆形渲染
- `renderEllipse()` - 椭圆渲染
- `renderLine()` - 直线渲染
- `renderPolyline()` - 折线渲染

#### 文件组织
```
renderer/
├── index.ts             # 统一导出
├── canvas-renderer.ts   # 主渲染器
└── shapes/              # 图形渲染器
    ├── index.ts
    ├── rectangle.ts
    ├── circle.ts
    ├── ellipse.ts
    ├── line.ts
    └── polyline.ts
```

### 4. 组件库模块 (Components)

#### 职责
- 提供 React 组件
- UI 交互逻辑
- 状态管理集成

#### 核心组件

**Canvas 组件**
```typescript
interface CanvasProps {
  document: PencilDocument;
  width?: number;
  height?: number;
}

function Canvas({ document, width, height }: CanvasProps): JSX.Element;
```

**LayerPanel 组件**
```typescript
interface LayerPanelProps {
  document: PencilDocument;
  selectedLayerId?: string;
  onLayerSelect: (layerId: string) => void;
  onLayerReorder: (fromIndex: number, toIndex: number) => void;
  onLayerToggleVisible: (layerId: string) => void;
  onLayerDelete: (layerId: string) => void;
```

#### 组件层次
```
LayerPanel (容器组件)

```

```
└── LayerPanel/           # 图层面板组件
    ├── index.ts
```

```
┌─────────────┐
│   User      │

└──────┬──────┘
       │
       ↓
┌─────────────┐
│   Event     │
│   Handler   │
└──────┬──────┘
       │
       ↓
┌─────────────┐
│   State     │
│   Update    │
│  (Immer)    │
└──────┬──────┘
       │
       ↓
┌─────────────┐
│   Render    │
│  (React)    │
└─────────────┘
```

### 状态管理

使用 Immer 进行不可变状态更新:

```typescript
const handleToggleVisible = (layerId: string) => {
  setDocument(produce(draft => {
    const layer = draft.layers.find(l => l.id === layerId);
    if (layer) {
      layer.visible = !layer.visible;
    }
  }));
};
```

## 扩展性设计

### 1. 图形类型扩展

添加新图形类型的步骤:
1. 在 `types/shape.ts` 定义新类型
2. 在 `renderer/shapes/` 创建渲染函数
3. 在 `CanvasRenderer.renderLayer()` 添加分支
4. 在 `validator.ts` 添加验证逻辑
5. 编写测试用例

### 2. 渲染器扩展

支持多种渲染后端:
- Canvas 2D (当前)
- WebGL (计划中)
- SVG (计划中)
- Skia (计划中)

### 3. 插件系统 (计划中)

## 性能优化

### 渲染优化
- 按需渲染: 只渲染可见图层
- Canvas 缓存: 缓存静态图层
- 批量更新: 合并多次状态更新

### 内存优化
- 对象池: 复用图形对象
- 虚拟列表: 大量图层时使用虚拟滚动

### 加载优化
- 代码分割: 按需加载模块
- 懒加载: 延迟加载非关键组件
