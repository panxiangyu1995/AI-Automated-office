## 核心概念速查

### 数据模型

```typescript
PencilDocument
├── version: string
├── metadata: DocumentMetadata
│   ├── created: string
│   ├── modified: string
│   └── title: string
├── canvas: CanvasConfig
│   ├── width: number
│   ├── height: number
│   └── backgroundColor: string
└── layers: Layer[]
    ├── id: string
    ├── type: 'shape'
    ├── name: string
    ├── visible: boolean
    ├── locked: boolean
    ├── opacity: number
    └── shape: Shape
        ├── RectangleShape
        ├── CircleShape
        ├── EllipseShape
        ├── LineShape
        └── PolylineShape
```

### 组件层次

```
App
├── Canvas (渲染器)
└── LayerPanel (图层面板)
    └── LayerList (图层列表)
        └── SortableLayerItem (可排序项)
            └── LayerItem (图层项)
```

### 模块依赖

```
@openpencil/core
├── types (类型定义)
├── format (格式处理)
│   └── parser, validator
├── renderer (渲染引擎)
│   └── shapes (图形渲染器)
└── components (UI 组件)
    ├── Canvas
    └── LayerPanel
```

## 开发命令速查

```bash
# 安装依赖
pnpm install

# 运行开发服务器
pnpm dev

# 运行测试
pnpm test

# 运行测试 (UI)
pnpm test:ui

# 生成测试覆盖率
pnpm test:coverage

# 构建项目
pnpm build

# 类型检查
pnpm tsc --noEmit
```
