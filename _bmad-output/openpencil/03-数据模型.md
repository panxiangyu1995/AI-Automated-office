# OpenPencil 数据模型

## 概述

OpenPencil 使用 TypeScript 类型系统定义严格的数据模型,确保类型安全和代码可维护性。所有数据结构都采用不可变设计,配合 Immer 进行状态管理。

## 核心数据结构

### 1. 文档模型 (PencilDocument)

文档是 OpenPencil 的顶层容器,包含所有设计数据。

```typescript
interface PencilDocument {
  version: string;              // 文档格式版本
  metadata: DocumentMetadata;   // 元数据
  canvas: CanvasConfig;         // 画布配置
  layers: Layer[];              // 图层数组
}
```

#### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| version | string | ✓ | 文档格式版本,当前为 "1.0.0" |
| metadata | DocumentMetadata | ✓ | 文档元数据 |
| canvas | CanvasConfig | ✓ | 画布配置 |
| layers | Layer[] | ✓ | 图层数组,按渲染顺序排列 |

#### 示例

```json
{
  "version": "1.0.0",
  "metadata": {
    "created": "2026-02-21T10:00:00Z",
    "modified": "2026-02-21T12:00:00Z",
    "title": "My Design"
  },
  "canvas": {
    "width": 800,
    "height": 600,
    "backgroundColor": "#F5F5F5"
  },
  "layers": [...]
}
```

### 2. 元数据模型 (DocumentMetadata)

```typescript
interface DocumentMetadata {
  created: string;    // 创建时间 (ISO 8601)
  modified: string;   // 修改时间 (ISO 8601)
  title: string;      // 文档标题
}
```

#### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| created | string | ✓ | 创建时间,ISO 8601 格式 |
| modified | string | ✓ | 最后修改时间,ISO 8601 格式 |
| title | string | ✓ | 文档标题 |

### 3. 画布配置模型 (CanvasConfig)

```typescript
interface CanvasConfig {
  width: number;            // 画布宽度 (像素)
  height: number;           // 画布高度 (像素)
  backgroundColor: string;  // 背景颜色 (CSS 颜色值)
}
```

#### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| width | number | ✓ | 画布宽度,单位像素 |
| height | number | ✓ | 画布高度,单位像素 |
| backgroundColor | string | ✓ | 背景颜色,CSS 颜色格式 (如 "#FFFFFF", "rgb(255,255,255)") |

### 4. 图层模型 (Layer)

图层是图形元素的容器,每个图层包含一个图形对象。

```typescript
interface Layer {
  id: string;          // 图层唯一标识符
  type: 'shape';       // 图层类型 (当前仅支持 shape)
  name: string;        // 图层名称
  visible: boolean;    // 是否可见
  locked: boolean;     // 是否锁定
  opacity: number;     // 不透明度 (0-1)
  shape: Shape;        // 图形对象
}
```

#### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| id | string | ✓ | 图层唯一标识符,建议使用 UUID |
| type | 'shape' | ✓ | 图层类型,当前仅支持 "shape" |
| name | string | ✓ | 图层名称,显示在图层面板中 |
| visible | boolean | ✓ | 是否可见,true 为可见 |
| locked | boolean | ✓ | 是否锁定,锁定后不可编辑 |
| opacity | number | ✓ | 不透明度,范围 0-1,1 为完全不透明 |
| shape | Shape | ✓ | 图形对象,联合类型 |

#### 示例

```json
{
  "id": "layer-1",
  "type": "shape",
  "name": "Red Rectangle",
  "visible": true,
  "locked": false,
  "opacity": 1,
  "shape": {
    "type": "rectangle",
    "x": 100,
    "y": 100,
    "width": 200,
    "height": 150,
    "fill": "#FF0000",
    "stroke": "#000000",
    "strokeWidth": 2
  }
}
```

## 图形类型系统

### 图形联合类型

```typescript
type Shape = 
  | RectangleShape 
  | CircleShape 
  | EllipseShape 
  | LineShape 
  | PolylineShape;
```

所有图形类型共享 `type` 字段作为判别属性 (Discriminated Union)。

### 1. 矩形 (RectangleShape)

```typescript
interface RectangleShape {
  type: 'rectangle';
  x: number;              // 左上角 X 坐标
  y: number;              // 左上角 Y 坐标
  width: number;          // 宽度
  height: number;         // 高度
  fill: string;           // 填充颜色
  stroke?: string;        // 描边颜色 (可选)
  strokeWidth?: number;   // 描边宽度 (可选)
}
```

#### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| type | 'rectangle' | ✓ | 类型标识 |
| x | number | ✓ | 左上角 X 坐标 |
| y | number | ✓ | 左上角 Y 坐标 |
| width | number | ✓ | 宽度,单位像素 |
| height | number | ✓ | 高度,单位像素 |
| fill | string | ✓ | 填充颜色,CSS 颜色格式 |
| stroke | string | ✗ | 描边颜色,CSS 颜色格式 |
| strokeWidth | number | ✗ | 描边宽度,单位像素 |

#### 示例

```json
{
  "type": "rectangle",
  "x": 100,
  "y": 100,
  "width": 200,
  "height": 150,
  "fill": "#FF0000",
  "stroke": "#000000",
  "strokeWidth": 2
}
```

interface LineShape {

### 5. 折线 (PolylineShape)

```typescript
interface PolylineShape {
  type: 'polyline';
  points: Array<{ x: number; y: number }>;  // 点数组
  stroke: string;                            // 描边颜色 (必需)
  strokeWidth: number;                       // 描边宽度 (必需)
  fill?: string;                             // 填充颜色 (可选,闭合时)
  closed?: boolean;                          // 是否闭合
}
```

#### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| type | 'polyline' | ✓ | 类型标识 |
| points | Array<{x, y}> | ✓ | 点数组,至少 2 个点 |
| stroke | string | ✓ | 描边颜色,必需 |
| strokeWidth | number | ✓ | 描边宽度,必需 |
| fill | string | ✗ | 填充颜色,闭合时有效 |
| closed | boolean | ✗ | 是否闭合,默认 false |

#### 示例

```json
{
  "type": "polyline",
  "points": [
    { "x": 100, "y": 100 },
    { "x": 200, "y": 150 },
    { "x": 300, "y": 100 }
  ],
  "stroke": "#000000",
  "strokeWidth": 2,
  "closed": false
}
```

## 数据验证

### 验证规则

#### 文档级验证
- `version` 必需
- `metadata` 必需
- `canvas` 必需
- `layers` 必需且为数组

#### 画布验证
- `width` 必需且为数字
- `height` 必需且为数字
- `backgroundColor` 必需且为字符串

#### 图层验证
- `id` 必需
- `type` 必需
- `name` 必需
- `visible` 必需
- `locked` 必需
- `opacity` 必需
- `shape` 必需

#### 图形验证

**通用验证**
- `type` 必需
- 根据类型进行特定验证

**矩形验证**
- `x`, `y`, `width`, `height` 必需且为数字
- `fill` 必需且为字符串

**圆形验证**
- `cx`, `cy` 必需且为数字
- `radius` 必需且为数字,必须 > 0
- `fill` 必需且为字符串

**椭圆验证**
- `cx`, `cy` 必需且为数字
- `rx`, `ry` 必需且为数字,必须 > 0
- `fill` 必需且为字符串

**直线验证**
- `x1`, `y1`, `x2`, `y2` 必需且为数字
- `stroke` 必需且为字符串
- `strokeWidth` 必需且为数字

**折线验证**
- `points` 必需且为数组,至少 2 个点
- 每个点的 `x`, `y` 必需且为数字
- `stroke` 必需且为字符串
- `strokeWidth` 必需且为数字

### 验证结果

```typescript
interface ValidationResult {
  valid: boolean;     // 是否有效
  errors: string[];   // 错误信息数组
}
```

### 验证示例

```typescript
const result = validateDocument(data);
if (!result.valid) {
  console.error('Validation errors:', result.errors);
}
```

## 类型安全

### TypeScript 配置

```json
{
  "compilerOptions": {
    "strict": true,
    "target": "ES2020",
    "module": "ESNext",
    "lib": ["ES2020", "DOM", "DOM.Iterable"]
  }
}
```

### 类型守卫

```typescript
function isRectangle(shape: Shape): shape is RectangleShape {
  return shape.type === 'rectangle';
}

function isCircle(shape: Shape): shape is CircleShape {
  return shape.type === 'circle';
}
```

### 类型推断

TypeScript 会根据 `type` 字段自动推断具体类型:

```typescript
function renderLayer(layer: Layer) {
  switch (layer.shape.type) {
    case 'rectangle':
      // TypeScript 知道 layer.shape 是 RectangleShape
      renderRectangle(ctx, layer.shape);
      break;
    case 'circle':
      // TypeScript 知道 layer.shape 是 CircleShape
      renderCircle(ctx, layer.shape);
      break;
  }
}
```

## 最佳实践

### 1. 图层 ID 生成
使用 UUID 或唯一标识符生成器:
```typescript
const layerId = `layer-${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
```

### 2. 时间戳格式
使用 ISO 8601 格式:
```typescript
const timestamp = new Date().toISOString();
```

### 3. 颜色格式
推荐使用标准格式:
- 十六进制: `#RRGGBB`
- RGB: `rgb(r, g, b)`
- RGBA: `rgba(r, g, b, a)`

### 4. 坐标系统
- 原点 (0, 0) 在左上角
- X 轴向右为正
- Y 轴向下为正

### 5. 图层顺序
- `layers` 数组顺序即为渲染顺序
- 数组末尾的图层在最上层
- 使用拖拽重新排序时更新数组顺序
