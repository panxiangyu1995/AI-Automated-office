# OpenPencil 渲染引擎

## 概述

OpenPencil 使用 Canvas 2D API 实现高性能的图形渲染引擎。渲染引擎负责将文档数据模型转换为可视化的图形输出,支持多种图形类型的渲染,并提供图层管理功能。

## 渲染架构

### 整体架构

```
┌─────────────────────────────────────────────┐
│           CanvasRenderer (主渲染器)          │
├─────────────────────────────────────────────┤
│  - render(document)                         │
│  - clear(canvas)                            │
│  - renderBackground(canvas)                 │
│  - renderLayer(layer)                       │
└─────────────────┬───────────────────────────┘
                  │
       ┌──────────┴──────────┐
       │   Shape Renderers   │
       └──────────┬──────────┘
                  │
    ┌─────────────┼─────────────┬─────────────┐
    │             │             │             │
┌───▼───┐    ┌───▼───┐    ┌───▼───┐    ┌───▼───┐
│Rect   │    │Circle │    │Ellipse│    │Line   │
│Renderer│   │Renderer│   │Renderer│   │Renderer│
└───────┘    └───────┘    └───────┘    └───────┘
```

### 渲染流程

```
render(document)
  │
  ├─→ clear(canvas)              // 清空画布
  │     └─→ ctx.clearRect()
  │
  ├─→ renderBackground(canvas)   // 渲染背景
  │     └─→ ctx.fillStyle + ctx.fillRect()
  │
  └─→ for each layer:           // 遍历图层
        │
        ├─→ check visible       // 检查可见性
        │
        └─→ renderLayer(layer)  // 渲染图层
              │
              ├─→ ctx.save()          // 保存状态
              ├─→ set opacity         // 设置透明度
              ├─→ renderShape()       // 渲染图形
              └─→ ctx.restore()       // 恢复状态
```

## 核心类

### CanvasRenderer

主渲染器类,负责协调整个渲染过程。

```typescript
class CanvasRenderer {
  private ctx: CanvasRenderingContext2D;
  
  constructor(canvas: HTMLCanvasElement) {
    const ctx = canvas.getContext('2d');
    if (!ctx) throw new Error('Canvas context not available');
    this.ctx = ctx;
  }
  
  render(document: PencilDocument): void;
  private clear(canvas: CanvasConfig): void;
  private renderBackground(canvas: CanvasConfig): void;
  private renderLayer(layer: Layer): void;
}
```

#### 构造函数

```typescript
const canvas = document.createElement('canvas');
canvas.width = 800;
canvas.height = 600;

const renderer = new CanvasRenderer(canvas);
```

**参数**
- `canvas: HTMLCanvasElement` - 目标 Canvas 元素

**异常**
- 当 Canvas 不支持 2D 上下文时抛出错误

#### render 方法

```typescript
renderer.render(document);
```

**参数**
- `document: PencilDocument` - 要渲染的文档对象

**行为**
1. 清空画布
2. 渲染背景色
3. 按顺序渲染所有可见图层

### 1. 矩形渲染器 (renderRectangle)

```typescript
function renderRectangle(
  ctx: CanvasRenderingContext2D,
```

#### 实现逻辑

```typescript
function renderRectangle(ctx: CanvasRenderingContext2D, shape: RectangleShape): void {
  // 1. 填充矩形
  ctx.fillStyle = shape.fill;
  ctx.fillRect(shape.x, shape.y, shape.width, shape.height);
  
  // 2. 描边矩形 (可选)
  if (shape.stroke && shape.strokeWidth) {
    ctx.strokeStyle = shape.stroke;
    ctx.lineWidth = shape.strokeWidth;
    ctx.strokeRect(shape.x, shape.y, shape.width, shape.height);
  }
}
```

#### 渲染效果

```
│                 │ ← stroke (可选)
│   fill color    │
│                 │
└─────────────────┘
```

### 2. 圆形渲染器 (renderCircle)


#### 实现逻辑

```typescript
function renderCircle(ctx: CanvasRenderingContext2D, shape: CircleShape): void {
  // 1. 开始路径
  ctx.beginPath();
  
  // 2. 绘制圆弧 (完整圆)
  ctx.arc(shape.cx, shape.cy, shape.radius, 0, Math.PI * 2);
  
  // 3. 填充
  if (shape.fill) {
    ctx.fillStyle = shape.fill;
    ctx.fill();
  }
  
  // 4. 描边 (可选)
  if (shape.stroke && shape.strokeWidth) {
    ctx.strokeStyle = shape.stroke;
    ctx.lineWidth = shape.strokeWidth;
    ctx.stroke();
  }
}
```

```typescript
function renderLine(ctx: CanvasRenderingContext2D, shape: LineShape): void {
  // 1. 开始路径
  ctx.beginPath();
  
  // 2. 移动到起点
  ctx.moveTo(shape.x1, shape.y1);
  
  // 3. 连接到终点
  ctx.lineTo(shape.x2, shape.y2);
  
  // 4. 描边 (必需)
  ctx.strokeStyle = shape.stroke;
  ctx.lineWidth = shape.strokeWidth;
  ctx.stroke();
}
```

### 5. 折线渲染器 (renderPolyline)

```typescript

  ctx: CanvasRenderingContext2D,
  shape: PolylineShape
```

#### 实现逻辑

```typescript
function renderPolyline(ctx: CanvasRenderingContext2D, shape: PolylineShape): void {
  if (shape.points.length < 2) return;
  
  // 1. 开始路径
  ctx.beginPath();
  
  // 2. 移动到第一个点
  ctx.moveTo(shape.points[0].x, shape.points[0].y);
  
  // 3. 连接所有点
  for (let i = 1; i < shape.points.length; i++) {
    ctx.lineTo(shape.points[i].x, shape.points[i].y);
  }
  
  // 4. 闭合路径 (可选)
  if (shape.closed) {
    ctx.closePath();
  }
  
  // 5. 填充 (可选,闭合时)
  if (shape.fill && shape.closed) {
    ctx.fillStyle = shape.fill;
    ctx.fill();
  }
  
  // 6. 描边 (必需)
  ctx.strokeStyle = shape.stroke;
  ctx.lineWidth = shape.strokeWidth;
  ctx.stroke();
}
```

#### 渲染效果

**开放折线**
```
  ●─────●
   \   /
    ●
```

**闭合折线**
```
  ●─────●
  │\   /│
  │ ●   │
  └─────┘
```

|-----|------|
| `ctx.closePath()` | 闭合路径 |

## 图层渲染

### 图层渲染流程

```typescript
private renderLayer(layer: Layer): void {
  // 1. 保存 Canvas 状态
  this.ctx.save();
  
  // 2. 设置图层透明度
  this.ctx.globalAlpha = layer.opacity;
  
  // 3. 根据图形类型调用对应渲染器
  switch (layer.shape.type) {
    case 'rectangle':
      renderRectangle(this.ctx, layer.shape);
      break;
    case 'circle':
      renderCircle(this.ctx, layer.shape);
      break;
    case 'ellipse':
      renderEllipse(this.ctx, layer.shape);
      break;
    case 'line':
      renderLine(this.ctx, layer.shape);
      break;
    case 'polyline':
      renderPolyline(this.ctx, layer.shape);
      break;
  }
  
  // 4. 恢复 Canvas 状态
  this.ctx.restore();
}
```

### 图层可见性

只有 `visible: true` 的图层才会被渲染:

```typescript
for (const layer of document.layers) {
  if (layer.visible) {
    this.renderLayer(layer);
  }
}
```

### 图层透明度

使用 `globalAlpha` 实现图层透明度:

```typescript
this.ctx.globalAlpha = layer.opacity; // 0-1 范围
```

### 渲染顺序

图层按照 `layers` 数组的顺序渲染:
- 数组索引 0 的图层在最底层
- 数组末尾的图层在最顶层

## Canvas 状态管理

### 状态保存与恢复

```typescript
// 保存状态
ctx.save();

// 修改状态
ctx.globalAlpha = 0.5;
ctx.fillStyle = '#FF0000';

// 恢复状态
ctx.restore();
```

### 状态栈

Canvas 使用栈结构管理状态:
- `save()` 将当前状态压栈
- `restore()` 从栈中弹出状态

### 状态包含内容

- `globalAlpha` - 全局透明度
- `fillStyle` - 填充样式
- `strokeStyle` - 描边样式
- `lineWidth` - 线宽
- `transform` - 变换矩阵
- 其他绘图状态

## 性能优化

### 1. 按需渲染

只渲染可见图层:

```typescript
if (layer.visible) {
  this.renderLayer(layer);
}
```

### 2. 状态最小化

只在必要时修改 Canvas 状态:

```typescript
// 不好的做法
ctx.fillStyle = '#FF0000';
ctx.fillRect(0, 0, 100, 100);
ctx.fillStyle = '#FF0000'; // 重复设置
ctx.fillRect(100, 0, 100, 100);

// 好的做法
ctx.fillStyle = '#FF0000';
ctx.fillRect(0, 0, 100, 100);
ctx.fillRect(100, 0, 100, 100);
```

### 3. 路径批处理

合并多个路径操作:

```typescript
// 不好的做法
for (const rect of rects) {
  ctx.strokeRect(rect.x, rect.y, rect.w, rect.h);
}

// 好的做法
ctx.beginPath();
for (const rect of rects) {
  ctx.rect(rect.x, rect.y, rect.w, rect.h);
}
ctx.stroke();
```

### 4. 缓存策略 (计划中)

- 缓存静态图层到离屏 Canvas
- 只重绘变化的图层
- 使用 `requestAnimationFrame` 优化动画

## React 集成

### Canvas 组件

```typescript
interface CanvasProps {
  document: PencilDocument;
  width?: number;
  height?: number;
}

function Canvas({ document, width, height }: CanvasProps) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const rendererRef = useRef<CanvasRenderer | null>(null);
  
  // 初始化渲染器
  useEffect(() => {
    if (canvasRef.current && !rendererRef.current) {
      rendererRef.current = new CanvasRenderer(canvasRef.current);
    }
  }, []);
  
  // 文档变化时重新渲染
  useEffect(() => {
    if (rendererRef.current && document) {
      rendererRef.current.render(document);
    }
  }, [document]);
  
  const canvasWidth = width || document.canvas.width;
  const canvasHeight = height || document.canvas.height;
  
  return (
    <canvas
      ref={canvasRef}
      width={canvasWidth}
      height={canvasHeight}
      style={{
        border: '1px solid #ccc',
        display: 'block'
      }}
    />
  );
}
```

## 扩展性

4. 编写测试用例
