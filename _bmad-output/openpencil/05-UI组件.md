# OpenPencil UI 组件

## 概述

OpenPencil 提供了一套基于 React 的 UI 组件库,用于构建设计编辑器界面。组件库采用函数式组件和 Hooks 设计,支持完整的用户交互功能。

## 组件架构

### 组件层次结构

```
App (应用容器)
├── Canvas (画布组件)
└── LayerPanel (图层面板)
    └── LayerList (图层列表)
        └── SortableLayerItem (可排序项)
            └── LayerItem (图层项)
```

### 组件依赖关系

```
┌─────────────────────────────────────────┐
│              App Component               │
│  ┌─────────────┐      ┌──────────────┐ │
│  │   Canvas    │      │  LayerPanel  │ │
│  │  (渲染器)   │      │  (交互控制)  │ │
│  └─────────────┘      └──────┬───────┘ │
│                              │          │
│                       ┌──────▼───────┐ │
│                       │  LayerList   │ │
│                       │  (拖拽排序)  │ │
│                       └──────┬───────┘ │
│                              │          │
│                       ┌──────▼───────┐ │
│                       │  LayerItem   │ │
│                       │  (单个图层)  │ │
│                       └──────────────┘ │
└─────────────────────────────────────────┘
```

## 核心组件

### 1. Canvas 组件

画布组件负责渲染文档内容。

#### 接口定义

```typescript
interface CanvasProps {
  document: PencilDocument;  // 要渲染的文档
  width?: number;            // 可选宽度
  height?: number;           // 可选高度
}

function Canvas({ document, width, height }: CanvasProps): JSX.Element;
```

#### 实现原理

```typescript
function Canvas({ document, width, height }: CanvasProps) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const rendererRef = useRef<CanvasRenderer | null>(null);
  
  // 初始化渲染器
  useEffect(() => {
    if (canvasRef.current && !rendererRef.current) {
      rendererRef.current = new CanvasRenderer(canvasRef.current);
    }
  }, []);
  
  // 文档变化时重新渲染
  useEffect(() => {
    if (rendererRef.current && document) {
      rendererRef.current.render(document);
    }
  }, [document]);
  
  const canvasWidth = width || document.canvas.width;
  const canvasHeight = height || document.canvas.height;
  
  return (
    <canvas
      ref={canvasRef}
      width={canvasWidth}
      height={canvasHeight}
      style={{
        border: '1px solid #ccc',
        display: 'block'
      }}
    />
  );
}
```

#### 使用示例

```typescript
function App() {
  const [document, setDocument] = useState<PencilDocument>(sampleDoc);

      </div>

```

### 2. LayerPanel 组件

图层面板组件提供图层管理界面。

#### 接口定义

```typescript
interface LayerPanelProps {
  document: PencilDocument;                      // 文档对象
  selectedLayerId?: string;                      // 选中的图层 ID
  onLayerSelect: (layerId: string) => void;      // 选择图层回调
  onLayerReorder: (fromIndex: number, toIndex: number) => void;  // 重排序回调
  onLayerToggleVisible: (layerId: string) => void;  // 切换可见性回调
  onLayerDelete: (layerId: string) => void;      // 删除图层回调
  onLayerRename: (layerId: string, newName: string) => void;  // 重命名回调
  onLayerOpacityChange: (layerId: string, opacity: number) => void;  // 透明度变化回调
}

function LayerPanel(props: LayerPanelProps): JSX.Element;
```

#### 实现原理

```typescript
function LayerPanel({
  document,
  selectedLayerId,
  onLayerSelect,
  onLayerReorder,
  onLayerToggleVisible,
  onLayerDelete,
  onLayerRename
}: LayerPanelProps) {
  const panelRef = useRef<HTMLDivElement>(null);
  
  // 键盘导航
  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      if (!selectedLayerId) return;
      
      const currentIndex = document.layers.findIndex(l => l.id === selectedLayerId);
      if (currentIndex === -1) return;
      
      switch (e.key) {
        case 'ArrowUp':
          e.preventDefault();
          if (currentIndex > 0) {
            onLayerSelect(document.layers[currentIndex - 1].id);
          }
          break;
          
        case 'ArrowDown':
          e.preventDefault();
          if (currentIndex < document.layers.length - 1) {
            onLayerSelect(document.layers[currentIndex + 1].id);
          }
          break;
          
        case 'Delete':
        case 'Backspace':
          e.preventDefault();
          onLayerDelete(selectedLayerId);
          break;
      }
    };
    
    const panel = panelRef.current;
    if (panel) {
      panel.addEventListener('keydown', handleKeyDown);
      return () => panel.removeEventListener('keydown', handleKeyDown);
    }
  }, [document.layers, selectedLayerId, onLayerSelect, onLayerDelete]);
  
  return (
    <div
      ref={panelRef}
      role="navigation"
      tabIndex={0}
      style={{
        width: '280px',
        height: '100%',
        backgroundColor: '#f5f5f5',
        borderLeft: '1px solid #ddd',
        padding: '16px',
        overflow: 'auto',
        outline: 'none'
      }}
    >
      <h3 style={{ margin: '0 0 12px 0', fontSize: '14px', fontWeight: 600 }}>
        图层
      </h3>
      <LayerList
        layers={document.layers}
        selectedLayerId={selectedLayerId}
        onLayerSelect={onLayerSelect}
        onLayerToggleVisible={onLayerToggleVisible}
        onLayerDelete={onLayerDelete}
        onLayerRename={onLayerRename}
        onLayerReorder={onLayerReorder}
      />
    </div>
  );
}
```

- ✅ 图层列表展示

- ✅ 键盘导航 (方向键)
- ✅ 键盘删除 (Delete/Backspace)
- ✅ 无障碍访问 (role, tabIndex)

### 3. LayerList 组件

图层列表组件实现拖拽排序功能。

#### 接口定义

```typescript
interface LayerListProps {
  layers: Layer[];                              // 图层数组
  selectedLayerId?: string;                     // 选中的图层 ID
  onLayerSelect: (layerId: string) => void;     // 选择图层回调
  onLayerToggleVisible: (layerId: string) => void;  // 切换可见性回调
  onLayerDelete: (layerId: string) => void;     // 删除图层回调
  onLayerRename: (layerId: string, newName: string) => void;  // 重命名回调
  onLayerReorder: (fromIndex: number, toIndex: number) => void;  // 重排序回调
}

function LayerList(props: LayerListProps): JSX.Element;
```

#### 实现原理

```typescript
function LayerList({
  layers,
  selectedLayerId,
  onLayerSelect,
  onLayerToggleVisible,
  onLayerDelete,
  onLayerRename,
  onLayerReorder
}: LayerListProps) {
  // 配置拖拽传感器
  const sensors = useSensors(
    useSensor(PointerSensor),
    useSensor(KeyboardSensor, {
      coordinateGetter: sortableKeyboardCoordinates,
    })
  );
  
  // 处理拖拽结束
  const handleDragEnd = (event: DragEndEvent) => {
    const { active, over } = event;
    
    if (over && active.id !== over.id) {
      const oldIndex = layers.findIndex(l => l.id === active.id);
      const newIndex = layers.findIndex(l => l.id === over.id);
      onLayerReorder(oldIndex, newIndex);
    }
  };
  
  return (
    <DndContext
      sensors={sensors}
      collisionDetection={closestCenter}
      onDragEnd={handleDragEnd}
    >
      <SortableContext
        items={layers.map(l => l.id)}
        strategy={verticalListSortingStrategy}
      >
        <ul role="list" style={{ listStyle: 'none', padding: 0, margin: 0 }}>
          {layers.map(layer => (
            <SortableLayerItem
              key={layer.id}
              layer={layer}
              isSelected={selectedLayerId === layer.id}
              onSelect={() => onLayerSelect(layer.id)}
              onToggleVisible={() => onLayerToggleVisible(layer.id)}
              onDelete={() => onLayerDelete(layer.id)}
              onRename={(newName) => onLayerRename(layer.id, newName)}
            />
          ))}
        </ul>
      </SortableContext>
    </DndContext>
  );
}
```

#### 特性

- ✅ 拖拽排序
- ✅ 键盘拖拽支持
- ✅ 碰撞检测
- ✅ 垂直列表策略

#### 实现原理

```typescript
function LayerItem({ 
  layer, 
  isSelected, 
  onSelect,
  onToggleVisible,
  onDelete,
  onRename,
  dragHandleProps
}: LayerItemProps) {
  const [isEditing, setIsEditing] = useState(false);
  const [editValue, setEditValue] = useState(layer.name);
  
  // 图形图标
  const getShapeIcon = (type: string) => {
    switch (type) {
      case 'rectangle': return '▭';
      case 'circle': return '○';
      case 'ellipse': return '⬭';
      case 'line': return '─';
      case 'polyline': return '⟍';
      default: return '◇';
    }
  };
  
  // 双击编辑
  const handleDoubleClick = (e: React.MouseEvent) => {
    e.stopPropagation();
    setIsEditing(true);
    setEditValue(layer.name);
  };
  
  // 键盘事件
  const handleKeyDown = (e: React.KeyboardEvent) => {
    if (e.key === 'Enter') {
      e.preventDefault();
      if (editValue.trim()) {
        onRename(editValue.trim());
      }
      setIsEditing(false);
    } else if (e.key === 'Escape') {
      e.preventDefault();
      setIsEditing(false);
      setEditValue(layer.name);
    }
  };
  
  // 失焦保存
  const handleBlur = () => {
    if (editValue.trim() && editValue !== layer.name) {
      onRename(editValue.trim());
    }
    setIsEditing(false);
  };
  
  return (
    <li
      role="listitem"
      onClick={onSelect}
      style={{
        padding: '8px 12px',
        cursor: 'pointer',
        backgroundColor: isSelected ? '#e3f2fd' : 'transparent',
        border: isSelected ? '2px solid #2196f3' : '2px solid transparent',
        borderRadius: '4px',
        marginBottom: '4px',
        display: 'flex',
        alignItems: 'center',
        gap: '8px'
      }}
    >
      {/* 拖拽手柄 */}
      <span 
        {...dragHandleProps}
        style={{ 
          cursor: 'grab',
          fontSize: '12px',
          color: '#666'
        }}
      >
        ⋮⋮
      </span>
      
      {/* 图形图标 */}
      <span style={{ fontSize: '16px' }}>
        {getShapeIcon(layer.shape.type)}
      </span>
      
      {/* 图层名称 (可编辑) */}
      {isEditing ? (
        <input
          type="text"
          value={editValue}
          onChange={(e) => setEditValue(e.target.value)}
          onKeyDown={handleKeyDown}
          onBlur={handleBlur}
          onClick={(e) => e.stopPropagation()}
          autoFocus
          style={{
            flex: 1,
            padding: '4px',
            border: '1px solid #2196f3',
            borderRadius: '2px'
          }}
        />
      ) : (
        <span
          onDoubleClick={handleDoubleClick}
          style={{ flex: 1 }}
        >
          {layer.name}
        </span>
      )}
      
      {/* 可见性切换 */}
      <button
        onClick={(e) => {
          e.stopPropagation();
          onToggleVisible();
        }}
        aria-label="Toggle visibility"
        style={{
          border: 'none',
          background: 'transparent',
          cursor: 'pointer',
          fontSize: '16px',
          opacity: layer.visible ? 1 : 0.3
        }}
      >
        👁
      </button>
      
      {/* 删除按钮 */}
      <button
        onClick={(e) => {
          e.stopPropagation();
          onDelete();
        }}
        aria-label="Delete layer"
        style={{
          border: 'none',
          background: 'transparent',
          cursor: 'pointer',
          fontSize: '16px'
        }}
      >
        🗑
      </button>
    </li>
  );
}
```

## 状态管理

### 使用 Immer 进行不可变更新

```typescript
import { produce } from 'immer';

function App() {
  const [document, setDocument] = useState<PencilDocument>(sampleDoc);
  const [selectedLayerId, setSelectedLayerId] = useState<string | null>(null);
  
  // 切换可见性
  const handleToggleVisible = (layerId: string) => {
    setDocument(produce(draft => {
      const layer = draft.layers.find(l => l.id === layerId);
      if (layer) {
        layer.visible = !layer.visible;
      }
    }));
  };
  
  // 重排序
  const handleReorder = (fromIndex: number, toIndex: number) => {
    setDocument(produce(draft => {
      const [removed] = draft.layers.splice(fromIndex, 1);
      draft.layers.splice(toIndex, 0, removed);
    }));
  };
  
  // 删除
  const handleDelete = (layerId: string) => {
    setDocument(produce(draft => {
      draft.layers = draft.layers.filter(l => l.id !== layerId);
    }));
    
    if (selectedLayerId === layerId) {
      setSelectedLayerId(null);
    }
  };
  
  // 重命名
  const handleRename = (layerId: string, newName: string) => {
    setDocument(produce(draft => {
      const layer = draft.layers.find(l => l.id === layerId);
      if (layer) {
        layer.name = newName;
      }
    }));
  };
  
  return (
    <div style={{ display: 'flex', height: '100vh' }}>
      <div style={{ flex: 1, padding: 20 }}>
        <Canvas document={document} />
      </div>
      <LayerPanel
        document={document}
        selectedLayerId={selectedLayerId}
        onLayerSelect={setSelectedLayerId}
        onLayerReorder={handleReorder}
        onLayerToggleVisible={handleToggleVisible}
        onLayerDelete={handleDelete}
        onLayerRename={handleRename}
        onLayerOpacityChange={() => {}}
      />
    </div>
  );
}
```

## 拖拽功能

### @dnd-kit 集成

OpenPencil 使用 @dnd-kit 实现拖拽排序功能。

#### 核心概念

1. **DndContext**: 拖拽上下文提供者
2. **SortableContext**: 可排序上下文
3. **useSortable**: 可排序 Hook
4. **Sensors**: 输入传感器 (鼠标、键盘)

#### 实现步骤

1. **配置传感器**
```typescript

  })

```

2. **创建可排序项**
```typescript
function SortableLayerItem({ layer, ... }: SortableLayerItemProps) {
  const {
    attributes,
    listeners,
    setNodeRef,
    transform,
    transition,
    isDragging
  } = useSortable({ id: layer.id });
  
  const style = {
    transform: CSS.Transform.toString(transform),
    transition,
    opacity: isDragging ? 0.5 : 1
  };
  
  return (
    <div ref={setNodeRef} style={style}>
      <LayerItem
        layer={layer}
        dragHandleProps={{ ...attributes, ...listeners }}
        {...otherProps}
      />
    </div>
  );
}
```

## 最佳实践

### 1. 组件职责单一
- Canvas 只负责渲染
- LayerPanel 只负责图层管理
- LayerItem 只负责单个图层展示

### 2. 状态提升
- 文档状态在 App 组件管理
- 通过 props 向下传递
- 通过回调向上更新

### 3. 性能优化
- 使用 `useRef` 缓存渲染器实例
- 使用 `useCallback` 缓存回调函数
- 避免不必要的重渲染

### 4. 类型安全
- 所有 props 都有明确的 TypeScript 类型
- 使用接口定义组件 API
- 严格的类型检查

### 5. 可访问性
- 提供键盘导航
- 使用 ARIA 属性
- 管理焦点状态
