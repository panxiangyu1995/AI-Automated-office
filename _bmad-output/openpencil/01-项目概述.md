# OpenPencil 项目概述

## 项目背景

OpenPencil 是对 Pencil VSCode 扩展的开源重新实现项目。原始 Pencil 是一个设计文件编辑器工具,由 highagency 开发,版本 0.6.26,官网为 https://pencil.dev。

### 原始项目信息
- **名称**: Pencil
- **版本**: 0.6.26
- **发布者**: highagency
- **官网**: https://pencil.dev
- **平台**: VSCode 扩展

### 开源实现目标
创建一个开源的、可自定义的设计文件编辑器,支持:
- `.pen` 文件格式的解析和渲染
- 多种图形元素的绘制和管理
- AI 工具集成 (通过 MCP 协议)
- 跨平台部署 (桌面应用、Web 应用、VSCode 扩展)

## 项目定位

### 核心价值
1. **开源透明**: 完全开源的代码库,便于社区贡献和定制
2. **模块化设计**: 核心库独立,支持多种部署方式
3. **AI 集成**: 支持 Claude、Codex 等 AI 工具集成
4. **高性能渲染**: 基于 Canvas 的渲染引擎

### 目标用户
- 需要设计文件编辑器的开发者
- 需要集成 AI 工具的设计团队
- 希望定制设计工具的企业用户
- 开源社区贡献者

## 技术栈

### 核心技术
- **语言**: TypeScript 5.3.3
- **构建工具**: Vite 5.0.12
- **测试框架**: Vitest 1.2.0
- **UI 框架**: React 18.2.0
- **状态管理**: Immer 10.0.3
- **拖拽功能**: @dnd-kit 6.1.0

### 开发工具
- **包管理**: pnpm 10.24.0
- **代码规范**: TypeScript strict mode
- **测试环境**: happy-dom + @testing-library/react
- **模块系统**: ESNext (ESM)

### 渲染技术
- **图形引擎**: Canvas 2D API
- **渲染方式**: 即时模式渲染
- **性能优化**: 按需渲染、图层缓存

## 核心功能

### 1. 文件格式支持
- `.pen` 文件格式解析
- JSON 格式存储
- Schema 验证
- 版本管理

### 2. 图形渲染
支持的图形类型:
- **Rectangle** (矩形): 支持填充、描边
- **Circle** (圆形): 支持填充、描边
- **Ellipse** (椭圆): 支持填充、描边
- **Line** (直线): 支持描边
- **Polyline** (折线): 支持描边、可选填充

### 3. 图层管理
- 图层列表展示
- 图层可见性切换
- 图层重命名
- 图层删除
- 拖拽排序
- 键盘导航 (方向键选择, Delete 删除)

### 4. 状态管理
- 使用 Immer 进行不可变状态更新
- React hooks 集成
- 响应式渲染

## 部署方式

### 桌面应用 (推荐)
- **技术**: Tauri + Rust (计划中)
- **大小**: 3-5MB 安装包
- **平台**: Windows (.msi) / macOS (.dmg) / Linux (.deb/.AppImage)
- **特点**: 原生性能、系统集成、离线使用

### Web 应用
- **技术**: Express + WebSocket (计划中)
- **访问**: 浏览器访问本地端口
- **特点**: 即开即用、多人协作、跨平台

### VSCode 扩展
- **技术**: VSCode Extension API (计划中)
- **安装**: VSCode Marketplace
- **特点**: 开发者友好、文件系统集成
