# Claude-Mem 集成建议

## 概述

本文档基于对 Claude-Mem 项目的系统性研究，为 AI-Automated-office 项目提供架构设计参考建议。

## 核心架构模式

### 1. 插件化钩子系统

**Claude-Mem 实现**:
- 5个生命周期钩子（SessionStart, UserPromptSubmit, PostToolUse, Stop, SessionEnd）
- 通过 hooks.json 配置声明式注册
- 钩子脚本独立运行，通过stdin/stdout通信

**可借鉴点**:
```
AI-Automated-office/
├── plugins/
│   ├── core/
│   │   └── hooks.json           # 核心钩子配置
│   ├── memory/
│   │   ├── hooks.json           # 记忆插件钩子
│   │   └── scripts/
│   └── automation/
│       ├── hooks.json           # 自动化插件钩子
│       └── scripts/
```

**建议实现**:
- 定义统一的插件接口规范
- 支持钩子的优先级和依赖管理
- 实现钩子的热加载和卸载

### 2. Worker服务架构

**Claude-Mem 实现**:
- 独立的Worker进程（Bun托管）
- HTTP API + SSE实时推送
- 后台异步处理

**可借鉴点**:
```
AI-Automated-office/
├── services/
│   ├── worker/
│   │   ├── WorkerService.ts     # 主服务
│   │   ├── routes/              # API路由
│   │   ├── agents/              # AI代理
│   │   └── events/              # 事件处理
│   └── core/
│       ├── DatabaseManager.ts
│       ├── SessionManager.ts
│       └── EventBus.ts
```

**建议实现**:
- 采用类似的Worker服务模式处理耗时任务
- 使用Express或Fastify构建HTTP API
- 实现SSE用于实时状态推送

### 3. 分层数据存储

**Claude-Mem 实现**:
- SQLite主存储 + FTS5全文搜索
- ChromaDB向量存储（可选）
- 文件系统辅助存储

**可借鉴点**:
```
AI-Automated-office/
├── data/
│   ├── sqlite/
│   │   ├── main.db              # 主数据库
│   │   └── fts/                 # 全文搜索
│   ├── vector/
│   │   └── embeddings/          # 向量存储
│   └── cache/
│       └── sessions/            # 会话缓存
```

**建议实现**:
- SQLite作为主存储引擎
- 集成向量数据库支持语义搜索
- 实现数据迁移和版本管理机制

class VectorSearchService {
  private client: ChromaClient;
  
  async index(observation: Observation): Promise<void> {
    const embedding = await this.generateEmbedding(observation);
    await this.client.add({
      id: observation.id,
      embedding: embedding,
      metadata: {
        type: observation.type,
        timestamp: observation.metadata.timestamp
      }
    });
  }
  
  async search(query: string, limit: number): Promise<SearchResult[]> {
    const queryEmbedding = await this.generateEmbedding(query);
    return await this.client.query({
      queryEmbeddings: queryEmbedding,
      nResults: limit
    });
  }
}

### SSE实时推送

**建议实现**:
```typescript
// SSE端点
app.get('/api/events', (req, res) => {
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  res.setHeader('Connection', 'keep-alive');
  
  const clientId = generateId();
  eventBus.subscribe(clientId, res);
  
  req.on('close', () => {
    eventBus.unsubscribe(clientId);
  });
});

// 事件广播
class EventBus {
  private clients: Map<string, Response> = new Map();
  
  subscribe(id: string, res: Response): void {
    this.clients.set(id, res);
  }
  
  unsubscribe(id: string): void {
    this.clients.delete(id);
  }
  
  broadcast(event: string, data: any): void {
    const message = `event: ${event}\ndata: ${JSON.stringify(data)}\n\n`;
    for (const res of this.clients.values()) {
      res.write(message);
    }
  }
}
```

## 错误处理与日志

### 日志系统

**建议实现**:
```typescript
enum LogLevel {
  DEBUG = 0,
  INFO = 1,
  WARN = 2,
  ERROR = 3
}

class Logger {
  constructor(
    private component: string,
    private level: LogLevel = LogLevel.INFO
  ) {}
  
  debug(message: string, context?: object): void {
    this.log(LogLevel.DEBUG, message, context);
  }
  
  info(message: string, context?: object): void {
    this.log(LogLevel.INFO, message, context);
  }
  
  warn(message: string, context?: object): void {
    this.log(LogLevel.WARN, message, context);
  }
  
  error(message: string, error?: Error, context?: object): void {
    this.log(LogLevel.ERROR, message, { ...context, error: error?.message });
  }
  
  private log(level: LogLevel, message: string, context?: object): void {
    if (level < this.level) return;
    
    const entry = {
      timestamp: new Date().toISOString(),
      level: LogLevel[level],
      component: this.component,
      message,
      ...context
    };
    
    // 写入文件和/或控制台
    this.writeLog(entry);
  }
}
```

### 错误恢复

**建议实现**:
```typescript
class ErrorRecovery {
  // 重试机制
  async withRetry<T>(
    fn: () => Promise<T>,
    options: { maxRetries: number; delay: number }
  ): Promise<T> {
    let lastError: Error;
    for (let i = 0; i < options.maxRetries; i++) {
      try {
        return await fn();
      } catch (error) {
        lastError = error;
        await this.delay(options.delay * Math.pow(2, i));
      }
    }
    throw lastError;
  }
  
  // 断路器
  circuitBreaker<T>(
    fn: () => Promise<T>,
    options: { threshold: number; timeout: number }
  ): () => Promise<T> {
    let failures = 0;
    let lastFailure: number;
    
    return async () => {
      if (failures >= options.threshold) {
        if (Date.now() - lastFailure < options.timeout) {
          throw new Error('Circuit breaker open');
        }
        failures = 0;
      }
      
      try {
        const result = await fn();
        failures = 0;
        return result;
      } catch (error) {
        failures++;
        lastFailure = Date.now();
        throw error;
      }
    };
  }
}
```

## 总结

### 核心借鉴点

1. **插件化架构**: 通过钩子系统实现松耦合扩展
2. **Worker服务模式**: 独立进程处理耗时任务，提供HTTP API
3. **渐进式披露**: 分层检索优化令牌使用
4. **分层数据存储**: SQLite + 向量数据库组合
5. **实时推送**: SSE实现状态同步

### 实施优先级

| 优先级 | 组件 | 说明 |
|--------|------|------|
| P0 | 数据层 | SQLite + 迁移系统 |
| P0 | 钩子系统 | 基础生命周期钩子 |
| P1 | Worker服务 | HTTP API + 异步处理 |
| P1 | 上下文生成 | 基础上下文注入 |
| P2 | 搜索系统 | FTS5全文搜索 |
| P2 | 向量搜索 | 语义搜索支持 |
| P3 | 实时推送 | SSE状态同步 |
| P3 | Web UI | 可视化界面 |

### 技术选型建议

| 层级 | 推荐技术 | 原因 |
|------|----------|------|
| 运行时 | Node.js + Bun | 兼容性好，性能优秀 |
| 数据库 | SQLite (bun:sqlite) | 轻量、高性能、易部署 |
| 向量存储 | ChromaDB / LanceDB | 开源、易集成 |
| HTTP框架 | Express / Fastify | 成熟稳定 |
| 构建工具 | esbuild | 快速、支持TypeScript |
| 测试框架 | Node.js内置 / Vitest | 简单高效 |
