# brain-mcp-cli 项目概述

## 项目定位

brain-mcp-cli 是一个**认知假肢（Cognitive Prosthetic）**系统，而非传统的记忆存储工具。其核心理念是：

> **其他AI记忆工具记住事实，brain-mcp记住你如何思考。**

### 核心价值主张

1. **对话考古学**：将成千上万的AI对话转化为可搜索的知识库
2. **认知状态重建**：重建你在某个领域的思考状态、开放问题、已做决策
3. **上下文恢复**：快速恢复数周前的工作上下文，避免重复思考
4. **思维轨迹追踪**：追踪想法如何随时间演变

## 项目特点

### 1. 多源数据整合

支持从多个AI平台导入对话历史：
- Claude Code（本地会话）
- Claude Desktop
- ChatGPT（导出文件）
- Clawdbot
- Cursor（计划中）
- Gemini CLI
- 通用JSONL格式

### 2. 本地优先架构

- **100%本地运行**：所有数据存储在本地机器
- **无云依赖**：核心功能完全离线可用
- **隐私保护**：无遥测、无跟踪、无需账户
- **零API成本**：嵌入模型本地运行

### 3. 渐进式功能层级

```
基础层：关键词搜索 + 日期浏览 + 统计
    ↓
嵌入层：语义搜索 + 综合分析 + 轨迹追踪
    ↓
摘要层：完整认知假肢工具（领域分析、决策追踪、上下文恢复）
```

### 4. MCP协议集成

通过Model Context Protocol (MCP)提供25个工具：
- 🔍 搜索工具（6个）
- 💬 对话工具（5个）
- 🧪 综合工具（4个）
- 📊 统计工具（2个）
- 🧠 认知假肢工具（8个）

## 技术栈

### 核心技术

| 技术 | 用途 | 特点 |
|------|------|------|
| **DuckDB** | 对话数据查询 | 列式存储、高性能分析查询 |
| **LanceDB** | 向量存储与检索 | 无服务器架构、支持混合搜索 |
| **FastEmbed** | 文本嵌入 | 轻量级（107MB）、无PyTorch依赖 |
| **MCP (FastMCP)** | 工具协议 | 标准化AI工具接口 |
| **FastAPI** | Dashboard Web界面 | 现代异步Web框架 |

### 数据格式

- **Parquet**：列式存储格式，用于对话和摘要数据
- **JSONL**：流式数据格式，用于导入和中间处理
- **LanceDB**：向量数据库格式

### 嵌入模型

**默认模型**：`BAAI/bge-small-en-v1.5`
- 33M参数
- 384维向量
- ~107MB下载
- 无需PyTorch

**备选模型**：`nomic-ai/nomic-embed-text-v1.5`
- 768维向量
- 需要sentence-transformers
