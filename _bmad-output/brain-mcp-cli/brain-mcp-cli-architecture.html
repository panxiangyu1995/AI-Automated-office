核心设计模式

🔌 插件注册模式

位置：brain_mcp/ingest/registry.py

实现原理：

  • 全局注册表存储摄入器实例
  • 装饰器自动注册
  • 解耦摄入器实现与核心系统
  • 支持动态添加新数据源
@register装饰器 BaseIngester基类
📐 抽象基类模式

位置：brain_mcp/ingest/base.py

核心接口：

  • source_type - 唯一标识符
  • display_name - 人类可读名称
  • discover() - 发现数据源
  • ingest() - 摄入数据
  • incremental_ingest() - 增量摄入
🎯 单例模式

位置：brain_mcp/server/db.py

实现方式：

  • 模块级缓存变量
  • 延迟初始化（Lazy Loading）
  • 避免重复加载大型模型
  • 连接复用，减少开销
⚙️ 配置中心模式

位置：brain_mcp/config.py

配置查找优先级：

  • 显式指定的路径
  • BRAIN_CONFIG 环境变量
  • BRAIN_HOME 环境变量
  • 当前目录的 config.toml
  • ~/.config/brain-mcp/config.toml

认知假肢核心功能

🧠 tunnel_state

功能：重建领域认知状态

输出：

  • 当前思考阶段
  • 开放问题列表
  • 已做决策历史
  • 活跃概念集合
  • 情感基调

→ "Load Game" 按钮，恢复你的思维状态

📈 thinking_trajectory

功能：追踪思维演变轨迹

输出：

  • 阶段演变时间线
  • 关键里程碑
  • 问题演变历史
  • 决策积累过程

→ 追踪想法如何随时间演变

🔄 switching_cost

功能：量化上下文切换成本

计算因素：

  • 开放问题成本
  • 重要性权重
  • 概念重叠减免
  • 综合成本评分

→ 量化切换领域的认知负荷

💤 dormant_contexts

功能：发现被遗忘的领域

识别标准：

  • 长时间未活跃
  • 存在开放问题
  • 重要性标记
  • 决策未完成

→ 发现你可能遗忘的重要主题

部署架构

🏠 本地优先架构
  • 100%本地运行 - 所有数据存储在本地机器
  • 无云依赖 - 核心功能完全离线可用
  • 隐私保护 - 无遥测、无跟踪、无需账户
  • 零API成本 - 嵌入模型本地运行
📦 部署方式
  • CLI工具 - brain-mcp命令行接口
  • MCP服务器 - 通过stdio与客户端通信
  • Dashboard - FastAPI Web界面（可选）
  • 配置文件 - TOML/YAML格式
