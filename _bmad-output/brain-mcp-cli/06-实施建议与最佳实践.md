# brain-mcp-cli 实施建议与最佳实践

## 1. 项目实施建议

### 1.1 技术选型建议

#### 1.1.1 存储技术

**推荐方案**：

| 场景 | 推荐技术 | 原因 |
|------|---------|------|
| 结构化数据存储 | Parquet + DuckDB | 列式存储、高压缩率、分析查询优化 |
| 向量数据存储 | LanceDB | 无服务器、自动索引、混合搜索 |
| 配置文件 | TOML | 人类可读、类型安全、Python 3.11+原生支持 |
| 流式数据 | JSONL | 增量追加友好、易于调试 |

**替代方案**：
- 如果需要更强的SQL支持：SQLite + FTS5
- 如果需要更强的向量检索：Milvus / Qdrant（但需要独立服务）
- 如果需要实时更新：Redis + RedisSearch

#### 1.1.2 嵌入模型

**推荐方案**：

| 模型 | 维度 | 大小 | 适用场景 |
|------|------|------|---------|
| BAAI/bge-small-en-v1.5 | 384 | 107MB | 英文、轻量级、快速 |
| nomic-ai/nomic-embed-text-v1.5 | 768 | 274MB | 英文、高质量、支持长文本 |
| BAAI/bge-m3 | 1024 | 2.2GB | 多语言、高质量 |

**选择建议**：
- 仅英文：bge-small-en-v1.5（默认）
- 需要高质量：nomic-embed-text-v1.5
- 多语言：bge-m3

#### 1.1.3 LLM提供者

**摘要生成推荐**：

| 提供者 | 模型 | 成本 | 质量 |
|--------|------|------|------|
| Anthropic | claude-sonnet-4-20250514 | 中 | 高 |
| OpenAI | gpt-4o-mini | 低 | 中 |
| Ollama | llama3.1:8b | 免费 | 中 |

**选择建议**：
- 追求质量：Claude Sonnet
- 追求性价比：GPT-4o-mini
- 追求隐私/免费：Ollama本地

def incremental_ingest(source_path: str, state: dict):
    """增量摄入"""
    # 1. 获取上次同步时间
    last_sync = state.get("last_sync")
    
    # 2. 只处理新文件
    all_files = list_files(source_path)
    if last_sync:
        new_files = [f for f in all_files if f.mtime > last_sync]
    else:
        new_files = all_files
    
    # 3. 摄入新文件
    records = []
    for file in new_files:
        records.extend(parse_file(file))
    
    return records, {"last_sync": datetime.now()}
```

from concurrent.futures import ThreadPoolExecutor

def parallel_ingest(files: list[Path], max_workers: int = 4):
    """并行摄入"""
    with ThreadPoolExecutor(max_workers=max_workers) as executor:
        results = executor.map(parse_file, files)
    
    all_records = []
    for records in results:

    return all_records

def validate_record(record: dict) -> tuple[bool, list[str]]:
    """验证记录"""
    errors = []
    
    # 必填字段
    required = ["id", "title", "created"]
    for field in required:
        if field not in record or not record[field]:
            errors.append(f"Missing required field: {field}")
    
    # 类型检查
    if "created" in record and not isinstance(record["created"], datetime):
        errors.append("created must be datetime")
    
    # 内容检查
    if "content" in record and len(record["content"]) > 100000:
        errors.append("content too long (max 100KB)")
    
    return len(errors) == 0, errors
```

    print(f"维度不匹配: {old_dim}d → {new_provider.dimension}d")
    
    # 2. 重建向量库
    response = input("重建向量库? (y/n): ")
    if response == "y":
        rebuild_vector_db()
