| Information | 一般信息 | 右下角，5秒自动消失 |
| Warning | 警告信息 | 右下角，需要手动关闭 |
| Error | 错误信息 | 右下角红色，需要手动关闭 |
| Progress | 长时间操作 | 右下角，显示进度条 |
