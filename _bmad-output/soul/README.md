## 关键发现

### SOUL.md 机制
- 作为上下文文件注入到系统提示
- 通过特殊指令引导 AI 遵循人格定义
- 在内存刷新时保持只读，确保人格稳定性

### Skill 加载机制
- 六级优先级的多源加载
- 三层智能限制（数量、大小、字符预算）
- 紧凑格式降级策略

### 心跳机制
- 五层预检查确保合理性
- 隔离会话模式节省 token
- HEARTBEAT_OK 确认机制避免无意义通知

### 定时任务机制
- 四种调度类型支持灵活配置
- 隔离代理执行确保独立性
- 完善的错误处理和超时机制
