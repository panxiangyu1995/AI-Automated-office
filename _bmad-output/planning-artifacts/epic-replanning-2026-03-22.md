## 1. 重排目标

本方案目标不是推翻现有 Epic 编号，而是重排后续实施顺序：

1. 保留已完成的 `Epic 1`、`Epic 2` 成果。
2. 将 `编辑器系统与动态模板渲染` 前置为 UI 基础设施。
3. 让后续部门模块基于“固定平台壳 + 动态业务渲染”建设，而不是继续堆固定页面。

---

## 2. 关键原则

1. 固定 UI 负责平台稳定性、安全和治理能力。  
2. 动态 UI 负责企业差异化最强的业务承载区。  
3. 混合 UI（固定壳 + 动态内容区）是主形态。  
4. 先做渲染基础设施，再做业务动态化。
