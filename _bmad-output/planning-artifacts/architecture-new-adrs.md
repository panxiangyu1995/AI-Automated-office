## 新增 ADR 详细说明（kilocode 研究成果）

### ADR-051: MCP 服务器启用/禁用机制

**状态：** 已纳入架构决策表

**决策内容：** MCP 服务器启用/禁用采用配置驱动 + 状态管理

**设计细节：**
- 配置字段：支持 `enabled: boolean` 字段控制每个 MCP 服务器的启用状态
- 状态管理：运行时动态连接/断开，状态持久化到本地存储
- 生命周期：
  ```
  配置加载 → 状态检查(enabled) → 连接尝试 → 状态更新(connected/disabled/failed)
                ↓
           enabled=false → 标记为 disabled，不尝试连接
  ```
- 动态控制：支持运行时通过 API 启用/禁用，无需重启应用
- 错误处理：连接失败标记为 failed 状态，提供错误信息，支持重试

**与现有 ADR-015 的关系：**
- ADR-015 定义 MCP 协议版本和连接模式
- ADR-051 补充启用/禁用状态和生命周期管理

**对应 FR：** FR13 (MCP服务扩展能力)

### ADR-052: 三级权限动作模型

**状态：** 已纳入架构决策表

**决策内容：** 权限控制采用 `ask` / `allow` / `deny` 三级动作模型

**设计细节：**
- `ask`：每次执行前询问用户确认（适合高风险操作）
- `allow`：自动允许执行（适合低风险、已授权操作）
- `deny`：自动拒绝执行（适合被禁止的操作）

**分层覆盖机制（高优先级覆盖低优先级）：**
```
平台级默认值
    ↓ 被覆盖
租户级配置（企业管理员设置）
    ↓ 被覆盖
部门级配置（部门主管设置）
    ↓ 被覆盖
用户级配置（个人偏好）
```

**与现有 ADR-018/019 的关系：**
- ADR-018 定义字段级权限后台配置
- ADR-019 定义敏感操作确认方式
- ADR-052 统一权限动作语义和分层覆盖规则

**对应 FR：** FR1020-FR1027 (工具权限与沙箱)

### ADR-053: 多模态附件输入交互

**状态：** 已纳入架构决策表

**决策内容：** 多模态附件输入支持拖拽、粘贴、文件选择三种方式

**设计细节：**
- **输入方式：**
  - 拖拽：从文件系统拖拽文件到输入区域
  - 粘贴：支持剪贴板图片粘贴（截图后直接粘贴）
  - 文件选择：点击附件按钮选择文件

- **支持格式：**
  - 图片：PNG、JPEG、GIF、WebP
  - 文档：PDF

- **交互设计：**
  - 缩略图预览（64x64）
  - 悬停显示删除按钮
  - 点击放大查看
  - 文件名显示在底部

- **权限模型：**
  - 附件跟随业务对象权限（如审批单的附件随审批单可见）
  - 支持 OCR 自动提取文字内容供 Agent 理解

**与现有 FR137-FR142 的关系：**
- FR137-FR142 定义审批附件功能需求
- ADR-053 定义通用附件输入交互范式，可被审批、聊天等场景复用

**对应 FR：** FR401 (多模态输入)、FR137-FR142 (审批附件)

### ADR-022-1: 命令黑白名单三层机制

**状态：** 已纳入架构决策表

**决策内容：** 命令黑白名单采用三层机制：黑名单（禁止）、白名单（允许）、灰名单（需确认）

**设计细节：**
- **黑名单（禁止执行）：**
  - 系统级危险命令：`rm -rf /`、`mkfs`、`dd` 等
  - 网络级危险命令：`nc`、`telnet`、SSH 隧道等
  - 权限提升命令：`sudo`、`su`、`chmod 777` 等
  - 自定义黑名单（管理员配置）

- **白名单（允许执行）：**
  - 文件操作：`ls`、`cat`、`grep`、`find` 等
  - 文本处理：`awk`、`sed`、`cut`、`sort` 等
  - 压缩解压：`tar`、`zip`、`unzip` 等
  - 自定义白名单（部门配置）

- **灰名单（需要确认）：**
  - 不在黑白名单中的命令
  - 首次执行的命令
  - 涉及敏感路径的命令

**与现有 ADR-022 的关系：**
- ADR-022 定义黑名单匹配模式（通配符）
- ADR-022-1 补充三层机制和具体命令分类

**对应 FR：** FR1023-FR1024 (网络/文件系统白名单)

## 与 kilocode 的差异总结

| 功能点 | kilocode 实现 | 我们项目的调整 |
|--------|--------------|---------------|
| MCP 配置 | 项目级 JSON 配置 | 租户级 + 部门级配置，支持动态启用/禁用 |
| 权限模型 | 简单的 ask/allow/deny | 分层覆盖（平台→租户→部门→用户） |
| 附件交互 | 本地临时存储，开发者场景 | 云端对象存储 + 业务对象权限跟随 |
| 命令安全 | 权限询问机制 | 三层黑白名单 + 审计记录 |

## 实施建议

1. **ADR-051 (MCP 启用/禁用)**：在 Capability Supply Layer 实现状态管理器
2. **ADR-052 (权限模型)**：在 Agent Runtime Layer 的 Permission Gate 实现
3. **ADR-053 (附件交互)**：在 Experience Layer 的 UI 组件实现
4. **ADR-022-1 (命令黑白名单)**：在 Agent Runtime Layer 的工具执行前检查
