**文档日期：** 2026-03-22  
**规划前提：**
- `Epic 1` 已完成
- `Epic 2` 已完成

## 一、近期总体目标

在保留现有固定平台壳的前提下，优先建立以下能力闭环：

1. 页面容器与渲染宿主
2. 编辑器注册与基础编辑能力
3. 动态模板运行时
4. 动态表单与动态详情页渲染
5. 以审批中心或销售模块作为动态化试点

目标不是立即做出完整低代码平台，而是先形成一条可运行的最小链路：

```text
Workbench / Sidebar / Route
  -> Page Host
  -> Editor Registry
  -> Schema Renderer
  -> Data Binding
  -> Permission Hooks
  -> Dynamic Form / Dynamic Detail
  -> Pilot Module
```

## 五、建议优先规划的 Stories

以下 Story 命名为建议版本，可在并入 `epics.md` 或生成 OpenSpec 时按正式编号调整。

### Epic 41：页面容器与渲染宿主

#### Story 41.1 Workbench 宿主化改造

**目标：**
- 将 Workbench 从固定页面渲染器改为统一宿主容器

**范围：**
- 定义页面宿主接口
- 支持静态页、动态页、编辑器页三类视图
- 支持页面切换和宿主生命周期

**验收重点：**
- 可以统一打开三类页面
- 不破坏现有固定页面入口
- 宿主具备错误边界和加载态

#### Story 41.2 路由容器化

**目标：**
- 路由只负责进入页面容器，不直接绑定具体业务组件

**范围：**
- 统一容器入口
- 页面上下文参数模型
- 容器层权限检查

**验收重点：**
- 路由支持静态和动态两类页面
- 未授权页面可被统一拦截

#### Story 41.3 Sidebar 资源入口化

**目标：**
- 将 Sidebar 从固定菜单升级为资源入口中心

**范围：**
- 固定导航项
- 动态资源项
- 编辑器入口
- 最近打开项

**验收重点：**
- Sidebar 可同时展示系统页面和动态资源入口
- 页面打开行为统一走宿主协议

#### Story 41.4 页面打开模式与上下文协议

**目标：**
- 定义 `static` / `dynamic` / `editor` 三类打开模式

**范围：**
- 页面标识
- 参数模型
- 数据源标识
- 权限上下文
- 生命周期回调

**验收重点：**
- 页面模式可被统一识别和调度
- 插件和内置模块使用同一协议

### Epic 39：内置编辑器与文档编辑

#### Story 39.1 文本编辑器内置能力

**目标：**
- 提供基础文本/富文本编辑能力

**范围：**
- 文本内容加载与保存
- 基础工具栏
- 只读/可编辑两种状态

#### Story 39.2 表格与结构化文档编辑

**目标：**
- 提供可嵌入业务场景的表格和结构化文档编辑能力

**范围：**
- 表格渲染
- 单元格编辑
- 基础文档结构块

#### Story 39.3 编辑器宿主接入

**目标：**
- 将内置编辑器接入 Workbench 和页面宿主

**范围：**
- 标签打开
- 保存状态提示
- 编辑器切换

### Epic 40：编辑器系统与动态模板渲染

#### Story 40.1 Editor Registry 与 Resolver

**目标：**
- 建立编辑器注册表和解析器

**范围：**
- 编辑器描述协议
- 文件/资源到编辑器映射
- 默认编辑器回退策略

**验收重点：**
- 可根据资源类型选择正确编辑器
- 注册冲突有明确规则

#### Story 40.2 基础 Schema Renderer

**目标：**
- 建立最小可用动态页面渲染器

**范围：**
- 基础布局节点
- 基础组件节点
- 渲染树解析
- 错误边界

**验收重点：**
- 可渲染卡片、列表、字段区块等基础结构

#### Story 40.3 数据绑定与条件渲染

**目标：**
- 支持动态页面真正使用数据

**范围：**
- 数据源引用
- 表达式绑定
- 条件显示
- 循环渲染

**验收重点：**
- 组件可绑定数据
- 区块可根据权限或状态显示/隐藏

#### Story 40.4 模板权限与安全边界

**目标：**
- 为动态模板加入平台级安全约束

**范围：**
- 组件白名单
- 数据源访问控制
- 动作权限检查
- 模板渲染审计点

**验收重点：**
- 模板不能绕过平台权限模型
- 审计链路可记录模板关键行为

#### Story 40.5 模板发布与版本管理基础能力

**目标：**
- 让模板具备最基础的版本治理能力

**范围：**
- 模板版本号
- 发布/回滚
- 默认模板指定

### Epic 42：动态表单与动态详情渲染

#### Story 42.1 动态表单字段协议

**目标：**
- 定义统一字段元数据结构

**范围：**
- 字段类型
- 默认值
- 校验规则
- 布局属性
- 可见性和可编辑性

#### Story 42.2 动态表单渲染器

**目标：**
- 根据字段协议生成可提交表单

**范围：**
- 输入控件映射
- 提交动作
- 校验反馈
- 只读态渲染

#### Story 42.3 动态详情页区块渲染

**目标：**
- 支持详情页主体按区块动态显示

**范围：**
- 字段区块
- 附件区块
- 关联数据区块
- 分析信息区块

#### Story 42.4 审批单内容动态化

**目标：**
- 将审批详情页的内容主体接入动态渲染

**范围：**
- 审批动作区保持固定
- 单据内容动态化
- 权限与流程状态联动

#### Story 42.5 工作台内容区动态卡片化

**目标：**
- 将首页和部门工作台的内容区改造为动态卡片布局

**范围：**
- 卡片配置
- 图表区块
- 待办区块
- 快捷入口区块
