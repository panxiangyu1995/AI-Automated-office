# CLI-Anything 项目概述

## 项目定位

CLI-Anything 是一个革命性的开源框架，旨在将**所有 GUI 软件转换为 AI Agent 可操作的 CLI 接口**。其核心理念是：

> **今天的软件为人而生，明天的用户是 Agent。CLI-Anything 是连接 AI Agent 与全世界软件的桥梁。**

## 核心价值

### 1. Agent 原生设计

传统软件为人类用户设计，依赖鼠标点击和视觉反馈。CLI-Anything 将这些操作转换为结构化命令：

```
GUI 操作流程:
用户点击菜单 → 选择功能 → 填写参数 → 确认执行 → 查看结果

CLI-Anything 流程:
Agent 发送命令 → CLI 执行 → 返回 JSON 结果
```

### 2. 通用适配能力

项目已成功为 **16+ 款主流软件** 生成 CLI 接口：

| 软件类别 | 软件名称 | CLI 命令 |
|---------|---------|----------|
| 图像编辑 | GIMP | `cli-anything-gimp` |
| 3D 建模 | Blender | `cli-anything-blender` |
| 音频编辑 | Audacity | `cli-anything-audacity` |
| 办公套件 | LibreOffice | `cli-anything-libreoffice` |
| 视频编辑 | Kdenlive, Shotcut | `cli-anything-kdenlive` |
| 矢量图形 | Inkscape | `cli-anything-inkscape` |
| 直播录制 | OBS Studio | `cli-anything-obs-studio` |
| 图表绘制 | Draw.io | `cli-anything-drawio` |

### 3. 自动化生成

通过 AI Agent（如 Claude Code）自动完成 CLI 构建：

```bash
# 一行命令生成完整 CLI
/cli-anything:cli-anything ./gimp
```

生成过程包含 7 个阶段：
1. 🔍 代码库分析
2. 📐 架构设计
3. 🔨 功能实现
4. 📋 测试规划
5. 🧪 测试实现
6. 📝 文档生成
7. 📦 发布安装

## 适用场景

### 场景 1: AI 编程助手

让 Claude Code、OpenCode 等 AI 编程助手能够操作专业软件：

```bash
# Agent 自动处理图像
cli-anything-gimp project new --name "banner"
cli-anything-gimp layer add --name "background"
cli-anything-gimp filter apply blur --radius 5
cli-anything-gimp export render output.png
```

### 场景 2: 自动化工作流

构建无需人工干预的自动化流程：

```python
# 自动化视频处理流程
def process_video(input_path, output_path):
    subprocess.run(["cli-anything-shotcut", "project", "new", "-o", "temp.json"])
    subprocess.run(["cli-anything-shotcut", "clip", "add", "0", input_path])
    subprocess.run(["cli-anything-shotcut", "filter", "add", "denoise", "--track", "0"])
    subprocess.run(["cli-anything-shotcut", "export", "render", output_path])
```

## 核心特性

### 1. 双模式运行

**REPL 模式**（交互式）：
```bash
$ cli-anything-audacity
╭──────────────────────────────────────────────────╮
│  ◆ cli-anything-audacity v1.0.0                  │
│  Audacity CLI — Audio editing from command line  │
│  Skill: /usr/lib/cli-anything-audacity/skills/SKILL.md
╰──────────────────────────────────────────────────╯
(audacity:untitled) > project new --name "podcast"
✓ Created project: podcast
(audacity:podcast) > track add --name "voice"
✓ Added track 0: voice
(audacity:podcast*) > 
```

**CLI 模式**（一次性）：
```bash
$ cli-anything-audacity --json project info -p podcast.json
{
  "name": "podcast",
  "tracks": 1,
  "duration": 0.0,
  "sample_rate": 44100
}
```

### 2. JSON 输出支持

所有命令支持 `--json` 标志，输出结构化数据：

```bash
# 人类可读格式
$ cli-anything-blender object list
Objects in scene:
  [0] Cube (type: MESH, location: (0, 0, 0))
  [1] Light (type: LIGHT, location: (5, 5, 5))

# Agent 友好格式
$ cli-anything-blender --json object list
{
  "objects": [
    {"index": 0, "name": "Cube", "type": "MESH", "location": [0, 0, 0]},
    {"index": 1, "name": "Light", "type": "LIGHT", "location": [5, 5, 5]}
  ],
  "count": 2
}
```

### 3. 状态管理与撤销重做

内置 Session 管理支持：
- 最多 50 级撤销历史
- 项目状态持久化
- 修改追踪

```bash
(audacity:podcast*) > track add --name "music"
✓ Added track 1: music
(audacity:podcast*) > session undo
↩ Undone: Add track 'music'
(audacity:podcast*) > session redo
↪ Redone: Add track 'music'
```

### 4. Skill 自动发现

每个 CLI 包含 SKILL.md 文件，定义：
- 功能列表和命令分组
- 参数说明和示例
- Agent 使用指南

Agent 可通过读取 SKILL.md 快速理解 CLI 的全部能力。

### 2. Token 优化

通过 CLI 接口显著减少 Token 消耗：

```
传统方式（自然语言描述）:
"请打开 GIMP，创建一个新项目，添加一个图层，命名为 background，
应用高斯模糊滤镜，半径设置为 5 像素，然后导出为 PNG 格式..."
（约 100+ tokens）

CLI-Anything 方式:
cli-anything-gimp --json project new
cli-anything-gimp layer add --name background
cli-anything-gimp filter apply blur --radius 5
cli-anything-gimp export render output.png
（约 30 tokens，节省 70%）
```

### 3. 效率提升

- **减少交互轮次**：一次命令完成复杂操作
- **确定性输出**：JSON 格式避免解析错误
- **自文档化**：`--help` 提供即时信息

## 总结

CLI-Anything 是一个成熟的、经过验证的框架，能够将任意 GUI 软件转换为 Agent 友好的 CLI 接口。其核心价值在于：

1. **标准化**：统一的命令结构和输出格式
2. **自动化**：AI Agent 可自动生成 CLI
3. **可扩展**：支持任意软件的适配
4. **高效**：显著减少 Token 消耗和交互轮次

对于 AI-Automated-office 项目，CLI-Anything 提供了一个现成的、经过验证的插件系统解决方案。
