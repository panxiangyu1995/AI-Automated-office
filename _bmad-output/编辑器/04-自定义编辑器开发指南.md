# VSCode 自定义编辑器开发指南

## 一、概述

VSCode 提供了自定义编辑器 API，允许扩展开发者为特定类型的文件创建专门的编辑器。本文档详细说明如何开发和注册自定义编辑器。

## 二、扩展点配置

### 2.1 package.json 配置

```json
{
    "contributes": {
        "customEditors": [{
            "viewType": "myExtension.customEditor",
            "displayName": "My Custom Editor",
            "priority": "default",
            "selector": [
                { "filenamePattern": "*.myext" },
                { "filenamePattern": "**/config/*.json" }
            ]
        }]
    }
}
```

### 2.2 配置字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `viewType` | string | 是 | 编辑器唯一标识，建议包含扩展 ID |
| `displayName` | string | 是 | 用户可见的编辑器名称 |
| `selector` | array | 是 | 文件选择器数组 |
| `priority` | string | 否 | 优先级：`default`、`option`、`builtin` |

### 2.3 选择器配置

```json
"selector": [
    {
        "filenamePattern": "*.myext"
    },
    {
        "filenamePattern": "**/special/*.json"
    }
]
```

## 三、API 接口

### 3.1 CustomReadonlyEditorProvider

只读编辑器提供者接口：

```typescript
interface CustomReadonlyEditorProvider<T extends CustomDocument = CustomDocument> {
    /**
     * 打开自定义文档
     * 当第一次为资源打开编辑器时调用
     */
    openCustomDocument(
        uri: Uri, 
        openContext: CustomDocumentOpenContext, 
        token: CancellationToken
    ): Thenable<T> | T;

    /**
     * 解析自定义编辑器
     * 在 openCustomDocument 之后调用，用于设置编辑器 UI
     */
    resolveCustomEditor(
        document: T, 
        webviewPanel: WebviewPanel, 
        token: CancellationToken
    ): Thenable<void> | void;
}
```

### 3.2 CustomEditorProvider

可编辑编辑器提供者接口：

```typescript
interface CustomEditorProvider<T extends CustomDocument = CustomDocument> 
    extends CustomReadonlyEditorProvider<T> {
    
    /**
     * 文档变更事件
     * 必须在编辑发生时触发，使编辑器标记为脏状态
     */
    readonly onDidChangeCustomDocument: Event<CustomDocumentEditEvent<T>> | Event<CustomDocumentContentChangeEvent<T>>;

    /**
     * 保存文档
     */
    saveCustomDocument(document: T, cancellation: CancellationToken): Thenable<void>;

    /**
     * 另存为
     */
    saveCustomDocumentAs(document: T, destination: Uri, cancellation: CancellationToken): Thenable<void>;

    /**
     * 还原文档
     */
    revertCustomDocument(document: T, cancellation: CancellationToken): Thenable<void>;

    /**
     * 备份文档（用于热退出）
     */
    backupCustomDocument(
        document: T, 
        context: CustomDocumentBackupContext, 
        cancellation: CancellationToken
    ): Thenable<CustomDocumentBackup>;
}
```

### 3.3 CustomDocument

自定义文档接口：

```typescript
interface CustomDocument {
    /**
     * 文档关联的 URI
     */
    readonly uri: Uri;

    /**
     * 文档被释放时触发
     */
    readonly onDidDispose: Event<void>;

    /**
     * 释放文档资源
     */
    dispose(): void;
}
```

## 四、实现示例

### 4.1 只读编辑器实现

```typescript
import * as vscode from 'vscode';

interface MyDocument extends vscode.CustomDocument {
    readonly content: string;
}

export class MyReadonlyEditorProvider implements vscode.CustomReadonlyEditorProvider<MyDocument> {
    
    constructor(private readonly context: vscode.ExtensionContext) {}
    
    async openCustomDocument(
        uri: vscode.Uri,
        openContext: vscode.CustomDocumentOpenContext,
        token: vscode.CancellationToken
    ): Promise<MyDocument> {
        // 读取文件内容
        const content = await vscode.workspace.fs.readFile(uri);
        const text = Buffer.from(content).toString('utf-8');
        
        return {
            uri,
            content: text,
            onDidDispose: new vscode.EventEmitter<void>().event,
            dispose: () => {}
        };
    }
    
    async resolveCustomEditor(
        document: MyDocument,
        webviewPanel: vscode.WebviewPanel,
        token: vscode.CancellationToken
    ): Promise<void> {
        // 设置 webview 标题
        webviewPanel.webview.options = {
            enableScripts: true
        };
        
        // 设置 webview 内容
        webviewPanel.webview.html = this.getHtmlForWebview(webviewPanel.webview, document);
        
        // 处理来自 webview 的消息
        webviewPanel.webview.onDidReceiveMessage(message => {
            switch (message.type) {
                case 'ready':
                    // 发送初始数据
                    webviewPanel.webview.postMessage({
                        type: 'init',
                        content: document.content
                    });
                    break;
            }
        });
    }
    
    private getHtmlForWebview(webview: vscode.Webview, document: MyDocument): string {
        return `<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>${document.uri.path}</title>
</head>
<body>
    <div id="content"></div>
    <script>
        const vscode = acquireVsCodeApi();
        
        window.addEventListener('message', event => {
            const message = event.data;
            switch (message.type) {
                case 'init':
                    document.getElementById('content').textContent = message.content;
                    break;
            }
        });
        
        vscode.postMessage({ type: 'ready' });
    </script>
</body>
</html>`;
    }
}
```

### 4.2 可编辑编辑器实现

```typescript
import * as vscode from 'vscode';

interface MyEditableDocument extends vscode.CustomDocument {
    content: string;
}

export class MyEditableEditorProvider implements vscode.CustomEditorProvider<MyEditableDocument> {
    
    private readonly _onDidChangeCustomDocument = new vscode.EventEmitter<vscode.CustomDocumentEditEvent<MyEditableDocument>>();
    readonly onDidChangeCustomDocument = this._onDidChangeCustomDocument.event;
    
    constructor(private readonly context: vscode.ExtensionContext) {}
    
    async openCustomDocument(
        uri: vscode.Uri,
        openContext: vscode.CustomDocumentOpenContext,
        token: vscode.CancellationToken
    ): Promise<MyEditableDocument> {
        let content = '';
        
        // 检查是否有备份
        if (openContext.backupId) {
            const backupUri = vscode.Uri.parse(openContext.backupId);
            const backupContent = await vscode.workspace.fs.readFile(backupUri);
            content = Buffer.from(backupContent).toString('utf-8');
        } else {
            const fileContent = await vscode.workspace.fs.readFile(uri);
            content = Buffer.from(fileContent).toString('utf-8');
        }
        
        const document: MyEditableDocument = {
            uri,
            content,
            onDidDispose: new vscode.EventEmitter<void>().event,
            dispose: () => {}
        };
        
        return document;
    }
    
    async resolveCustomEditor(
        document: MyEditableDocument,
        webviewPanel: vscode.WebviewPanel,
        token: vscode.CancellationToken
    ): Promise<void> {
        webviewPanel.webview.options = {
            enableScripts: true
        };
        
        webviewPanel.webview.html = this.getHtmlForWebview(webviewPanel.webview, document);
        
        webviewPanel.webview.onDidReceiveMessage(message => {
            switch (message.type) {
                case 'ready':
                    webviewPanel.webview.postMessage({
                        type: 'init',
                        content: document.content
                    });
                    break;
                    
                case 'edit':
                    const oldContent = document.content;
                    document.content = message.content;
                    
                    // 触发编辑事件
                    this._onDidChangeCustomDocument.fire({
                        document,
                        label: 'Edit',
                        undo: () => {
                            document.content = oldContent;
                        },
                        redo: () => {
                            document.content = message.content;
                        }
                    });
                    break;
            }
        });
    }
    
    async saveCustomDocument(
        document: MyEditableDocument,
        cancellation: vscode.CancellationToken
    ): Promise<void> {
        const content = Buffer.from(document.content, 'utf-8');
        await vscode.workspace.fs.writeFile(document.uri, content);
    }
    
    async saveCustomDocumentAs(
        document: MyEditableDocument,
        destination: vscode.Uri,
        cancellation: vscode.CancellationToken
    ): Promise<void> {
        const content = Buffer.from(document.content, 'utf-8');
        await vscode.workspace.fs.writeFile(destination, content);
    }
    
    async revertCustomDocument(
        document: MyEditableDocument,
        cancellation: vscode.CancellationToken
    ): Promise<void> {
        const content = await vscode.workspace.fs.readFile(document.uri);
        document.content = Buffer.from(content).toString('utf-8');
    }
    
    async backupCustomDocument(
        document: MyEditableDocument,
        context: vscode.CustomDocumentBackupContext,
        cancellation: vscode.CancellationToken
    ): Promise<vscode.CustomDocumentBackup> {
        const backupUri = vscode.Uri.joinPath(
            context.destinationFolder,
            document.uri.path.replace(/\//g, '_')
        );
        
        const content = Buffer.from(document.content, 'utf-8');
        await vscode.workspace.fs.writeFile(backupUri, content);
        
        return {
            id: backupUri.toString(),
            delete: () => vscode.workspace.fs.delete(backupUri)
        };
    }
    
    private getHtmlForWebview(webview: vscode.Webview, document: MyEditableDocument): string {
        return `<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>${document.uri.path}</title>
</head>
<body>
    <textarea id="editor" style="width: 100%; height: 100%;"></textarea>
    <script>
        const vscode = acquireVsCodeApi();
        const editor = document.getElementById('editor');
        
        window.addEventListener('message', event => {
            const message = event.data;
            if (message.type === 'init') {
                editor.value = message.content;
            }
        });
        
        editor.addEventListener('input', () => {
            vscode.postMessage({
                type: 'edit',
                content: editor.value
            });
        });
        
        vscode.postMessage({ type: 'ready' });
    </script>
</body>
</html>`;
    }
}
```

## 五、注册编辑器

### 5.1 在扩展激活时注册

```typescript
export function activate(context: vscode.ExtensionContext) {
    // 注册只读编辑器
    context.subscriptions.push(
        vscode.window.registerCustomEditorProvider(
            'myExtension.readonlyEditor',
            new MyReadonlyEditorProvider(context),
            {
                supportsMultipleEditorsPerDocument: false,
                webviewOptions: {
                    retainContextWhenHidden: true
                }
            }
        )
    );
    
    // 注册可编辑编辑器
    context.subscriptions.push(
        vscode.window.registerCustomEditorProvider(
            'myExtension.editableEditor',
            new MyEditableEditorProvider(context),
            {
                supportsMultipleEditorsPerDocument: true
            }
        )
    );
}
```

### 5.2 注册选项

```typescript
interface CustomEditorProviderOptions {
    /**
     * 是否支持同一文档在多个编辑器组中打开
     * 默认为 false
     */
    supportsMultipleEditorsPerDocument?: boolean;
    
    /**
     * Webview 选项
     */
    webviewOptions?: {
        /**
         * 当 webview 隐藏时是否保持上下文
         * 设为 true 可以避免切换回来时重新加载
         */
        retainContextWhenHidden?: boolean;
        
        /**
         * 是否启用脚本
         * 默认为 true
         */
        enableScripts?: boolean;
        
        /**
         * 允许加载的本地资源
         */
        localResourceRoots?: vscode.Uri[];
    };
}
```

### 6.1 性能优化

1. **使用 retainContextWhenHidden**：
   ```typescript
   vscode.window.registerCustomEditorProvider(
       'myExtension.editor',
       provider,
       {
           webviewOptions: {
               retainContextWhenHidden: true
           }
       }
   );
   ```

2. **延迟加载内容**：
   ```typescript
   async resolveCustomEditor(document, webviewPanel, token) {
       // 先显示加载状态
       webviewPanel.webview.html = '<div>Loading...</div>';
       
       // 异步加载内容
       const content = await loadContent(document.uri);
       webviewPanel.webview.html = renderContent(content);
   }
   ```

3. **增量更新**：
   ```typescript
   // 只发送变更部分
   webviewPanel.webview.postMessage({
       type: 'update',
       changes: incrementalChanges
   });
   ```

### 6.2 错误处理

```typescript
async openCustomDocument(uri, openContext, token) {
    try {
        const content = await vscode.workspace.fs.readFile(uri);
        return createDocument(content);
    } catch (error) {
        if (error instanceof vscode.FileSystemError) {
            vscode.window.showErrorMessage(`Failed to open file: ${error.message}`);
        }
        throw error;
    }
}
```

### 6.3 取消支持

```typescript
async openCustomDocument(uri, openContext, token) {
    const content = await vscode.workspace.fs.readFile(uri);
    
    // 检查是否已取消
    if (token.isCancellationRequested) {
        return;
    }
    
    return createDocument(content);
}
```

## 八、常见问题

### 8.1 编辑器不显示

检查以下项：
1. `viewType` 是否唯一
2. `selector` 中的 Glob 模式是否正确
3. 扩展是否正确激活

### 8.2 文件无法保存

确保实现了：
1. `saveCustomDocument` 方法
2. `onDidChangeCustomDocument` 事件正确触发
3. 文件内容正确写入

### 8.3 Webview 内容不更新

确保：
1. `enableScripts` 选项已启用
2. 消息监听器正确设置
3. `postMessage` 正确调用
