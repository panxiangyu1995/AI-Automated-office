## 核心概念速查

### 编辑器优先级

| 优先级 | 数值 | 说明 |
|--------|------|------|
| `exclusive` | 5 | 独占编辑器，优先级最高 |
| `default` | 4 | 默认编辑器 |
| `builtin` | 3 | 内置编辑器 |
| `option` | 1 | 可选编辑器，优先级最低 |

### 关键服务

| 服务 | 职责 |
|------|------|
| `EditorResolverService` | 编辑器解析，根据资源匹配编辑器 |
| `TextEditorService` | 文本编辑器管理，注册默认编辑器 |
| `CustomEditorService` | 自定义编辑器管理 |
| `EditorGroupsService` | 编辑器组管理 |

### 关键扩展点

| 扩展点 | 用途 |
|--------|------|
| `customEditors` | 注册自定义编辑器 |
| `notebooks` | 注册 Notebook 编辑器 |
