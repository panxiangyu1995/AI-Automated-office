## 五、合并编辑器

合并编辑器不通过 Glob 模式注册，而是通过特定的输入类型触发。

| 输入类型 | 编辑器 ID | 说明 |
|----------|-----------|------|
| `IResourceMergeEditorInput` | `mergeEditor` | 三方合并编辑器 |

**注册位置**：`src/vs/workbench/contrib/mergeEditor/browser/view/mergeEditor.ts`

**注册方式**：
```typescript
editorResolverService.registerEditor(
    '*',  // 匹配所有资源
    {
        id: MergeEditorInput.ID,
        label: localize('mergeEditor', "Merge Editor"),
        priority: RegisteredEditorPriority.default,
    },
    {},
    {
        createMergeEditorInput: (mergeEditorInput, group) => {
            return { editor: this.instantiationService.createInstance(MergeEditorInput, ...) };
        }
    }
);
```

## 九、用户自定义映射

用户可以通过 `workbench.editorAssociations` 设置自定义文件类型与编辑器的关联：

```json
{
    "workbench.editorAssociations": {
        "*.hex": "hexEditor.hexedit",
        "*.svg": "imagePreview.previewEditor",
        "*.pdf": "pdf.preview"
    }
}
```

### 9.1 设置优先级

用户设置的优先级顺序（从高到低）：

1. **工作区设置** (`workspaceValue`) - 最高优先级
2. **用户设置** (`userValue`)
3. **默认设置** (`defaultValue`) - 最低优先级

### 9.2 设置应用逻辑

```typescript
// 位于 editorResolverService.ts
getAssociationsForResource(resource: URI): EditorAssociations {
    const associations = this.getAllUserAssociations();
    let matchingAssociations = associations.filter(association => 
        association.filenamePattern && globMatchesResource(association.filenamePattern, resource)
    );
    
    // 按 Glob 长度排序，更长的 Glob 更具体
    matchingAssociations = matchingAssociations.sort(
        (a, b) => (b.filenamePattern?.length ?? 0) - (a.filenamePattern?.length ?? 0)
    );
    
    return matchingAssociations;
}
```

## 十、编辑器选择决策流程

```
用户打开文件
      ↓
提取资源 URI
      ↓
检查用户设置关联 ──→ 找到 ──→ 使用指定编辑器
      ↓ 未找到
查找所有匹配的编辑器
      ↓
按优先级排序
      ↓
检查是否有 exclusive 编辑器 ──→ 有 ──→ 使用 exclusive 编辑器
      ↓ 无
选择最高优先级编辑器
      ↓
创建编辑器输入
      ↓
打开编辑器
```

## 十一、扩展开发指南

### 11.1 注册自定义编辑器

在 `package.json` 中添加：

```json
{
    "contributes": {
        "customEditors": [{
            "viewType": "myExtension.customEditor",
            "displayName": "My Custom Editor",
            "priority": "default",
            "selector": [
                { "filenamePattern": "*.myext" },
                { "filenamePattern": "**/myconfig.json" }
            ]
        }]
    }
}
```

### 11.2 实现 CustomEditorProvider

```typescript
export class MyCustomEditorProvider implements vscode.CustomEditorProvider {
    async openCustomDocument(uri: vscode.Uri, openContext: vscode.CustomDocumentOpenContext, token: vscode.CancellationToken): Promise<MyCustomDocument> {
        // 创建并返回文档
    }
    
    async resolveCustomEditor(document: MyCustomDocument, webviewPanel: vscode.WebviewPanel, token: vscode.CancellationToken): Promise<void> {
        // 设置 webview 内容
    }
    
    async saveCustomDocument(document: MyCustomDocument, token: vscode.CancellationToken): Promise<void> {
        // 保存文档
    }
}
```

### 11.3 注册 Provider

```typescript
export function activate(context: vscode.ExtensionContext) {
    context.subscriptions.push(
        vscode.window.registerCustomEditorProvider(
            'myExtension.customEditor',
            new MyCustomEditorProvider(),
            { supportsMultipleEditorsPerDocument: false }
        )
    );
}
```
