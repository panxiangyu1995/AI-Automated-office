# OpenClaw 决策层架构详解

## 一、决策层概述

决策层是 OpenClaw Agent 的"大脑"，负责接收感知层处理后的信息，基于上下文和记忆进行推理、规划和决策。决策层的核心是将用户意图转化为可执行的行动计划。

## 七、思维链推理

### 7.1 CoT 推理支持

OpenClaw 支持多种推理增强模式：

#### 显式思考标签

```xml
<thinking>
内部推理过程...
</thinking>

<final>
用户可见响应...
</final>
```

#### 隐式推理

```
通过工具调用序列实现隐式推理：
1. read(file) - 收集信息
2. grep(pattern) - 搜索分析
3. write(result) - 执行决策
```

## 八、决策执行流程

### 8.1 TAO 循环 (Think-Act-Observe)

```
┌─────────────────────────────────────────────────────────────────┐
│                      TAO 循环                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│    ┌─────────┐                                                  │
│    │  Think  │ 分析当前状态与目标，规划下一步策略                 │
│    └────┬────┘                                                  │
│         │                                                       │
│         ▼                                                       │
│    ┌─────────┐                                                  │
│    │   Act   │ 选择工具并生成参数，执行调用                      │
│    └────┬────┘                                                  │
│         │                                                       │
│         ▼                                                       │
│    ┌─────────┐                                                  │
│    │ Observe │ 获取执行结果，更新上下文理解                      │
│    └────┬────┘                                                  │
│         │                                                       │
│         └──────────────────────────────────────▶ 循环继续        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
