# OpenClaw 多智能体协作机制

## 一、多智能体协作概述

OpenClaw 支持多种多智能体协作模式，包括子代理（Subagent）、ACP 协议集成和 BMAD 工作流框架。这些机制使得复杂任务可以被分解并由专门的 Agent 协同完成。

## 六、协作模式对比

### 6.1 协作模式选择

| 模式 | 适用场景 | 特点 | 复杂度 |
|------|----------|------|--------|
| 管道式 | 线性业务流程 | 任务串行传递 | 低 |
| 分层式 | 复杂决策场景 | 管理-执行分离 | 中 |
| 网状式 | 动态业务场景 | Agent 自由交互 | 高 |
| 联邦式 | 跨域业务整合 | 松耦合协作 | 高 |

### 6.2 OpenClaw 支持的模式

```typescript
// 本地子代理 - 分层式
sessions_spawn({ runtime: "subagent" })

// ACP 外部 Agent - 联邦式
sessions_spawn({ runtime: "acp", agentId: "codex" })

// BMAD 工作流 - 管道式
workflow: "4-implementation/dev-story/workflow.yaml"
```
