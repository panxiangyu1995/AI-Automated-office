# OpenClaw 工具调用系统详解

## 一、工具调用概述

工具调用（Tool Calling/Function Calling）是 OpenClaw Agent 与外部世界交互的核心机制。它使大语言模型能够检测用户请求需要外部数据或行动，并生成结构化输出来指定调用的函数及参数。

### 6.3 策略管道

```typescript
// src/agents/tool-policy-pipeline.ts
export function applyToolPolicyPipeline(params: {
  tools: AnyAgentTool[];
  policies: ToolPolicyStep[];
}): AnyAgentTool[] {
  let result = params.tools;
  for (const step of params.policies) {
    result = step.apply(result);
  }
  return result;
}
```

### 6.4 常用策略步骤

```typescript
// 构建默认策略管道
export function buildDefaultToolPolicyPipelineSteps(params: {
  cfg: OpenClawConfig;
  agentId: string;
  sessionKey?: string;
  senderIsOwner?: boolean;
}): ToolPolicyStep[] {
  return [
    // 1. 所有者权限检查
    { name: "owner_policy", apply: (tools) => applyOwnerOnlyToolPolicy(tools, senderIsOwner) },
    
    // 2. 允许/拒绝列表
    { name: "allowlist", apply: (tools) => applyAllowlist(tools, allowList) },
    
    // 3. 子代理策略
    { name: "subagent", apply: (tools) => applySubagentPolicy(tools, isSubagent) },
    
    // 4. 沙箱策略
    { name: "sandbox", apply: (tools) => applySandboxPolicy(tools, sandboxConfig) },
  ];
}
```

## 十二、工具调用最佳实践

### 12.1 工具设计原则

- **单一职责**：每个工具做一件事
- **明确描述**：描述清楚工具用途
- **参数验证**：严格验证输入参数
- **错误处理**：提供有意义的错误信息

### 12.2 性能优化

- 批量操作支持
- 结果缓存
- 异步执行
- 超时控制

### 12.3 安全考虑

- 默认拒绝策略
- 最小权限原则
- 敏感操作审批
- 审计日志
