# OpenClaw 感知层架构详解

## 一、感知层概述

感知层是 OpenClaw Agent 的"感官系统"，负责接收和处理来自多个外部通道的输入信息。它实现了多模态感知能力，能够处理文本、图像、语音等多种输入类型。

### 2.3 通道类型处理

| 通道类型 | 模块路径 | 特殊能力 |
|----------|----------|----------|
