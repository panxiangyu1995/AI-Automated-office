# OpenClaw 记忆层架构详解

## 一、记忆层概述

记忆层是 OpenClaw Agent 的"知识库"，负责存储和检索历史信息、项目知识和长期记忆。通过向量嵌入和混合搜索技术，实现了高效的语义检索能力。

├── MEMORY.md           # 总体记忆概述

- 定期更新关键决策
- 记录重要上下文变化
- 清理过时信息
- 保持简洁聚焦

### 14.4 性能优化

- 合理设置分块大小
- 使用嵌入缓存
- 配置适当的并发
- 定期清理索引
