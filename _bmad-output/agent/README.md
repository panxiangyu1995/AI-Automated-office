### 源码模块

| 模块 | 路径 | 功能 |
|------|------|------|
| Agent 核心 | `src/agents/` | Agent 运行、工具、子代理 |

## 快速参考

### 关键配置文件

```
~/.openclaw/
├── config.json           # 主配置
├── sessions/             # 会话存储
└── agents/
    └── <agentId>/
        ├── agent/        # Agent 工作目录
        └── auth-profiles.json  # 认证配置
```

### 常用命令

```bash
# 启动网关
openclaw gateway start

# 查看状态
openclaw status

# 配置管理
openclaw config get <key>
openclaw config apply

# 通道管理
openclaw channels status
```
