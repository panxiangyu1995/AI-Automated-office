# Proposal: Org Chart View

## 变更类型
- [x] 新功能
- [ ] 修复
- [ ] 优化
- [ ] 重构

## 背景

Epic 2 用户认证与部门权限系统已进入效率增强阶段。Story 2.8 旨在构建组织架构图可视化功能，让员工和管理层能够直观查看企业组织架构，了解部门层级和员工汇报关系。

### 业务背景
- 员工需要查看组织架构图（FR106）
- 管理层需要了解人员分布和汇报关系
- 新员工入职需要快速了解组织架构

### 技术背景
- 前端采用 React + TypeScript + Shadcn/ui（ADR-001）
- 数据来源于云端 Go 后端的组织架构 API
- 需要支持大型组织的性能优化

## 目标

构建组织架构图可视化页面，包括：
1. 部门树形结构可视化
2. 员工汇报关系展示
3. 部门详情面板
4. 性能优化（折叠、虚拟滚动）

## 范围

### 包含
- 创建组织架构图页面组件
- 实现树形/矩阵布局切换
- 部门节点折叠/展开功能
- 部门详情面板（负责人、成员列表）
- 员工汇报关系可视化
- 虚拟滚动和懒加载优化

### 不包含
- 组织架构编辑功能（在 Story 2.3 中实现）
- 员工信息编辑功能（在 Story 2.2 中实现）
- 导出组织架构图（可在后续迭代中实现）

## 影响范围

### 前端
- `src/features/hr/components/OrgChart/` - 新增组织架构组件
- `src/features/hr/hooks/useOrgChart.ts` - 新增数据获取 Hook
- `src/pages/hr/OrgChartPage.tsx` - 新增页面入口

### 后端
- 复用 `GET /api/admin/departments/tree` 接口
- 复用 `GET /api/admin/users` 接口

### 数据库
- 无新增表，复用 departments、users、positions 表

## 风险评估

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 大型组织渲染性能问题 | 高 | 高 | 实现虚拟滚动和懒加载 |
| 树形布局计算复杂 | 中 | 中 | 使用成熟的可视化库（如 react-organizational-chart） |
| 响应式布局适配 | 中 | 低 | 提供缩放和平移功能 |

## 实施计划

1. **Step 1**: 创建 OrgChart 基础组件结构
2. **Step 2**: 实现树形布局和节点渲染
3. **Step 3**: 实现部门详情面板
4. **Step 4**: 实现员工汇报关系展示
5. **Step 5**: 添加折叠/展开功能
6. **Step 6**: 实现虚拟滚动和性能优化
7. **Step 7**: 测试和优化
