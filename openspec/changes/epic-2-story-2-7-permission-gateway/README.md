## Technical Approach

### 权限网关架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    权限网关校验顺序                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 租户隔离检查                                                │
│     ├── 验证 TenantID 有效性                                    │
│     └── 确保请求资源属于当前租户                                │
│                                                                 │
│  2. 用户状态校验                                                │
│     ├── 检查用户是否已登录                                      │
│     ├── 检查用户是否被禁用                                      │
│     └── 检查会话是否有效                                        │
│                                                                 │
│  3. 角色权限校验                                                │
│     ├── 获取用户角色                                            │
│     ├── 获取角色权限列表                                        │
│     └── 检查是否拥有所需权限                                    │
│                                                                 │
│  4. 个人覆盖权限校验                                            │
│     ├── 获取用户权限覆盖                                        │
│     └── 应用覆盖规则计算最终权限                                │
│                                                                 │
│  5. 数据范围校验                                                │
│     ├── 获取用户数据范围权限                                    │
│     └── 应用数据过滤条件                                        │
│                                                                 │
│  6. 字段级权限校验                                              │
│     ├── 获取用户字段权限                                        │
│     └── 应用字段过滤/脱敏规则                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 统一 403 响应契约

```json
{
  "code": "PERMISSION_DENIED",
  "http_status": 403,
  "message": "当前账号无权限执行该操作",
  "resource": "auth.user.update",
  "required_permission": "auth_user_write",
  "apply_entry": "/permissions/apply?resource=auth.user.update",
  "trace_id": "req-20260318-xxxx"
}
```
