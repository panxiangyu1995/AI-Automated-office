# Proposal: 部门模块基础框架

## 变更类型
- [x] 新功能
- [ ] 重构
- [ ] 优化
- [ ] 开发

## 背景

部门模块是本产品的核心组成部分。每个企业都有多个业务部门（人事、销售、财务、仓储、审批、管理层等），部门作为能力包的容器，为用户提供差异化的 AI 能力支持。

当前 Agent 核心框架已完成，但缺少部门模块的基础设施，无法承载具体的业务部门功能。

## 目标

创建部门模块的基础架构，包括：
1. 部门能力包注册机制
2. 部门加载器接口
3. 部门间通信基础
4. 部门管理 UI

## 范围

### 包含
- 部门能力包数据模型
- 部门注册表机制
- 部门加载器接口
- 部门间通信协议
- 部门管理 UI 页面

### 不包含
- 具体部门的业务功能（由后续 Story 实现）
- 部门权限模型（复用现有三层权限）
- 部门市场（独立 Story）

## 影响范围

### 后端
