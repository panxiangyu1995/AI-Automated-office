# 提案: Agent多租户支持

## 1. 背景与问题

当前Agent运行时缺少tenant_id上下文传递，部分工具调用未校验租户权限，存在跨租户数据泄露风险。

## 2. 目标

完善Agent多租户支持，确保：
- Agent运行时正确获取和传递tenant_id
- 工具调用时校验tenant_id匹配
- 跨租户访问返回明确错误

## 3. 覆盖需求

- NFR13: 多租户数据隔离，数据库级隔离，跨租户访问严格禁止
- FR470: Agent调用工具前会自动检查用户是否有该工具的调用权限
- FR471: 无权限时，Agent会提示用户并说明如何获取权限

## 4. 预期效果

- Agent会话创建时自动注入tenant_id
- 所有工具调用自动携带tenant_id上下文
- 跨租户访问被正确拦截
