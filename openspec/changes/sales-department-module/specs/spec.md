# Specification: Sales销售部门模块

## 需求来源
- FR140: 用户可以管理客户信息
- FR141: 用户可以生成报价单
- FR142: AI可以辅助生成报价单内容
- FR143: 用户可以生成合同
- FR144: AI可以辅助生成合同内容
- FR145: 用户可以跟踪订单状态

## 验收场景
### Scenario 1: AI生成报价单
- **GIVEN** 销售选择了客户和产品规格
- **WHEN** 点击AI生成报价单
- **THEN** AI生成报价单草稿供确认

### Scenario 2: AI生成合同
- **GIVEN** 销售选择了客户和报价单
- **WHEN** 点击AI生成合同
- **THEN** AI生成合同草稿供确认
