## 功能规格

### 用户旅程

#### Journey 1: 新用户首次使用
1. 启动应用 → 显示主界面
2. 配置 Agent → 设置模型
3. 创建会话 → 开始对话
4. 使用部门功能 → HR 模块

#### Journey 2: 企业管理员
1. 登录系统 → 认证成功
2. 配置部门 → 启用 HR、财务
3. 创建员工 → 测试 HR 功能
4. 提交审批 → 测试审批流

#### Journey 3: 日常使用
1. 查看消息 → 收到通知
2. 与 Agent 对话 → AI 回复
3. 使用工具 → 完成业务操作
4. 查看历史 → 检索历史对话
