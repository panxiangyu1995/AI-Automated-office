# Tasks: Integration Test Plan

## 任务列表

### 任务 1: 配置测试环境
- **描述**: 配置 Playwright 测试环境和测试数据库
- **文件**: 
  - `playwright.config.ts`
  - `tests/config/test-env.ts`
- **验收**: 测试环境可正常运行

### 任务 2: 创建测试数据
- **描述**: 创建测试用的用户、角色、部门数据

  - `tests/fixtures/users.json`
  - `tests/fixtures/roles.json`

- **验收**: 测试数据可正确加载

### 任务 5: 编写角色权限测试

### 任务 6: 编写部门管理测试

## 执行顺序

```
1. 配置测试环境
      ↓
2. 创建测试数据
      ↓
3-9. 编写各模块测试（可并行）
      ↓
10. 配置 CI 测试流水线
```
