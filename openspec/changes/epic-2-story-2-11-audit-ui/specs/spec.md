# Specification: Audit Query and Export UI

## 需求来源

### PRD 需求
- **FR33**: 管理员可以导入和导出用户数据（审计导出）

### UX 规范
- **UX-01**: 使用 Shadcn/ui 组件
- **UX-02**: 表格筛选和排序

## 功能规格

### 验收场景

#### Scenario 1: 查看审计日志列表
- **GIVEN** 管理员登录系统
- **WHEN** 访问审计日志页面
- **THEN** 显示审计日志列表
  - 按时间倒序排列
  - 分页显示

#### Scenario 2: 筛选审计日志
- **GIVEN** 管理员在审计页面
- **WHEN** 设置筛选条件
- **THEN** 列表按条件筛选
  - 支持事件类型筛选
  - 支持时间范围筛选
  - 支持操作人筛选

#### Scenario 3: 查看审计详情
- **GIVEN** 管理员在审计列表
- **WHEN** 点击某条审计日志
- **THEN** 显示详情弹窗
  - 显示完整审计信息
  - 显示变更前后值

#### Scenario 4: 导出审计日志
- **GIVEN** 管理员设置筛选条件
- **WHEN** 点击导出按钮
- **THEN** 下载审计日志文件
  - 支持 CSV 格式
  - 支持 Excel 格式

## 交付物

1. 审计查询 API
2. 审计导出 API
3. 前端审计页面
4. 导出功能
