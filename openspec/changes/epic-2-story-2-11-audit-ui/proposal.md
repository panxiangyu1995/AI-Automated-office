# Proposal: Audit Query and Export UI

## 变更类型
- [x] 新功能
- [ ] 修复
- [ ] 优化
- [ ] 重构

## 背景

审计日志模型和事件集成已完成，现需要提供用户友好的查询界面和导出功能，方便管理员查看和分析审计数据。

## 目标

1. 对接审计日志列表查询 API（复用后端已提供接口）
2. 构建前端审计日志表格组件
3. 实现多维度筛选功能
4. 实现审计日志导出功能

## 范围

### 包含
- 审计日志查询 API 对接（复用后端已提供接口）
- 前端审计日志表格
- 事件类型筛选
- 时间范围筛选
- 操作人筛选
- 审计日志导出（CSV/Excel）

### 不包含
- 审计日志模型（E2-S2.11-01）
- 审计事件集成（E2-S2.11-02）

## 依赖关系

### 前置依赖
- E2-S2.11-01: Structured audit log model
- E2-S2.11-02: Audit event integration
