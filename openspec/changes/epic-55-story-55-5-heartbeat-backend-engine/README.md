# Epic 55, Story 55.5: 心跳机制后端执行引擎

## 概述

实现心跳机制的后端执行引擎，支持定期Agent回合执行、HEARTBEAT.md检查清单解析、活动时段配置、轻量上下文与隔离会话模式、以及静默处理机制。

心跳机制是AI助手的主动式通知系统，允许AI定期检查状态并主动向用户发送通知，实现从"被动响应"到"主动服务"的转变。

## 验收标准

1. **心跳调度器**: 实现可配置间隔的心跳调度器（默认30分钟）
2. **预检查机制**: 心跳执行前完成预检查（用户状态、活跃时段、上下文预算、资源可用性）
3. **HEARTBEAT.md解析**: 支持读取和解析工作区HEARTBEAT.md检查清单
4. **静默处理**: 无待办时返回HEARTBEAT_OK并静默处理
5. **活动时段**: 支持活动时段配置与时区设置
6. **会话模式**: 支持轻量上下文与隔离会话两种模式
7. **投递机制**: 支持显式投递目标与通知策略
8. **唤醒模式**: 支持立即唤醒与"下次心跳"执行模式
9. **成本优化**: 清单为空时跳过执行以节省成本
10. **事件发射**: 心跳事件可观测、可审计
