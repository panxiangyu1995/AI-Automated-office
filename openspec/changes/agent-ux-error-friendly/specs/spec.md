# Agent模块UX错误信息友好化 - 规格说明

## Spec

### 1. 错误翻译规格

| 项目 | 规格 |
|------|------|
| 翻译粒度 | 错误码级别 |
| 返回结构 | {title, message, action?, originalError?} |
| 默认错误 | 通用"出错了"消息 |

### 2. 错误码映射表

| 错误码 | 标题 | 消息 | 操作 |
|--------|------|------|------|
| ERR_NETWORK_TIMEOUT | 网络连接超时 | 请检查网络后重试 | 重试 |
| ERR_AUTH_TOKEN_EXPIRED | 登录已过期 | 请重新登录 | 重新登录 |
| ERR_STORAGE_QUOTA_EXCEEDED | 存储空间不足 | 请清理后重试 | 查看详情 |
| ERR_TOOL_NOT_FOUND | 工具不可用 | 请稍后重试 | 重试 |
| ERR_AGENT_LOOP_DETECTED | 对话循环 | 已自动停止 | 开始新对话 |

### 3. 表单验证规格

| 项目 | 规格 |
|------|------|
| 验证时机 | onChange实时验证 |
| 错误显示 | 输入框下方红色提示 |
| 动画效果 | fade-in slide-in-from-top-1 |

---

## 验收测试用例

| 场景 | 期望结果 |
|------|---------|
| 网络超时 | 显示"网络连接超时"toast |
| Token过期 | 显示"登录已过期"并有重新登录按钮 |
| 表单空提交 | 实时显示"名称不能为空" |
| 名称格式错误 | 实时显示"只能包含字母、数字、下划线" |
