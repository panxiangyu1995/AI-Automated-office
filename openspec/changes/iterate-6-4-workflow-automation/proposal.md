# 提案: 工作流自动化

## 1. 背景与问题

当前系统已有cron_schedule等定时任务基础，但缺少完整的工作流编排引擎，无法支持复杂的业务流程自动化。

## 2. 目标

实现基础工作流编排引擎，支持：
- 工作流定义（步骤+条件分支）
- 工作流执行和状态跟踪
- 工作流暂停和恢复
- 审批节点集成

## 3. 覆盖需求

- FR15: 用户可以设置定时任务由AI助手自动执行
- FR120: 用户可以通过与AI对话生成审批流程
- FR121: AI可以通过调用tools+skills自动创建流程模板
- FR122: 用户可以手动创建自定义审批流程
- FR127: 系统可以在AI生成或用户创建流程时自动生成对应数据表

## 4. 预期效果

- 支持工作流DSL定义
- 支持顺序、分支、循环等控制流
- 支持人工审批节点
- 支持工作流状态持久化
