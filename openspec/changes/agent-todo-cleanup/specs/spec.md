# Agent模块TODO清理与调试代码移除 - 规格说明

## Spec

### 1. 内容安全检查规格

| 项目 | 规格 |
|------|------|
| 最大内容长度 | 65535字符 |
| 敏感词库 | 可配置的关键词列表 |
| 返回结构 | {safe: bool, reason?: string, flagged: bool} |

### 2. 消息同步规格

| 项目 | 规格 |
|------|------|
| 同步状态 | pending, syncing, synced, failed |
| 合并策略 | 时间戳优先 |
| 重试机制 | 3次指数退避 |

### 3. Webhook投递规格

| 项目 | 规格 |
|------|------|
| 超时时间 | 30秒 |
| 重试次数 | 3次 |
| 签名算法 | HMAC-SHA256 |

### 4. 调试代码移除标准

| 类型 | 处理方式 |
|------|---------|
| console.log | 移除或条件化(#dev) |
| println! | 移除或改用tracing |
| dbg! | 移除 |
| eprintln! | 改用tracing::warn |

---

## 验收测试用例

| 场景 | 期望结果 |
|------|---------|
| 发送敏感词消息 | 返回safe=false |
| 发送超长消息 | 返回safe=false |
| 断网同步 | 标记failed，3次重试 |
| Webhook投递失败 | 重试3次后标记失败 |
