# Proposal: 记忆系统三层架构

## 问题陈述

当前系统缺少完整的三层记忆架构实现：
1. **向量数据库未集成**: 虽然有vector模块骨架，但未与记忆系统完整集成
2. **三层权限隔离缺失**: L1个人记忆、L2企业知识库、L3图记忆的权限边界未实现
3. **混合检索未实现**: 向量检索 + BM25关键词检索的融合搜索未完成
4. **智能更新决策缺失**: ADD/UPDATE/DELETE/NONE智能决策机制未实现
5. **记忆Hook系统缺失**: 无法自动捕获会话事件并更新记忆

## 目标

实现完整的三层记忆架构，使AI助手能够：
1. 跨会话记忆用户偏好和关键事实
2. 共享企业级知识给租户全员
3. 智能决策记忆更新策略
4. 高效检索相关记忆内容
5. 支持本地优先和云端同步

## 解决方案

### 核心模块

1. **MemoryIngestion** - 摄入层
   - Hook生命周期事件捕获
   - 预处理（噪声过滤、隐私剥离）
   - 异步入队

2. **MemoryStorage** - 存储层
   - SQLite（会话、消息、观察、摘要）
   - sqlite-vec（本地向量检索）
   - Qdrant（云端向量服务）

3. **MemoryRetrieval** - 检索层
   - 混合检索（向量 + BM25）
   - RRF融合排序
   - 渐进式披露

4. **MemoryHooks** - Hook系统
   - SessionStart/End
   - UserPromptSubmit
   - PostToolUse
   - Stop

5. **CognitiveLayer** - 认知层
   - 领域状态建模
   - 思维轨迹维护
   - 切换成本计算

6. **SmartUpdate** - 智能更新
   - ADD/UPDATE/DELETE/NONE决策
   - 冲突检测
   - 版本管理

## 实现路径

### Phase 1: 存储层基础
- 完善memory_store.rs
- 集成sqlite-vec向量检索
- 实现三层权限隔离

### Phase 2: 摄入与Hook
- 实现Hook系统
- 事件捕获与处理
- 异步入队机制

### Phase 3: 检索层
- 实现混合检索
- RRF融合排序
- 渐进式披露

### Phase 4: 智能更新
- 实现智能决策机制
- 冲突检测与解决
- 版本管理

### Phase 5: 前端集成
- 记忆管理界面
- 配置界面
- 可视化展示

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 向量检索性能 | 大量记忆时检索变慢 | 使用索引优化、分页检索 |
| 权限泄露 | 跨层访问敏感数据 | 严格权限检查、审计日志 |
| 存储膨胀 | 记忆数据快速增长 | 智能压缩、过期清理 |
| 同步冲突 | 本地云端数据不一致 | 冲突检测、合并策略 |

## 成功指标

1. 记忆检索响应时间 < 200ms
2. 三层权限隔离100%正确
3. 智能更新决策准确率 > 90%
4. 混合检索召回率 > 95%
5. 用户可管理自己的记忆数据
