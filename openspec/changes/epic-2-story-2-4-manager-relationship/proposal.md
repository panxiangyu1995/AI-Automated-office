# Proposal: Direct Manager Relation

## Why (背景与动机)

直属上级关系是组织架构的重要组成部分，支持：
- 审批流程的上级路由
- 组织架构图的汇报关系展示
- 权限继承和数据范围控制

本变更实现用户的直属上级关系管理，确保数据完整性和合法性。

## What Changes (变更内容)

### 新增功能
1. **用户上级关系**
   - 用户模型添加 manager_id 字段
   - 支持设置和变更直属上级

2. **上级查询 API**
   - 查询用户的完整上级链
   - 查询用户的直接下属列表

3. **约束校验**
   - 循环上级链检测（A -> B -> C -> A）
   - 跨租户上级设置阻止
   - 自己设置为上级阻止

4. **前端集成**
   - 用户编辑表单添加上级选择器
   - 选择器支持搜索和过滤

### 技术实现
- 在 Go 云端实现上级管理 API
- 使用递归算法检测循环
- 前端使用用户选择器组件

## Capabilities 影响

### 新增 Capabilities
- `relationship`: 用户直属上级关系管理

### 修改 Capabilities
- `admin-api`: 用户 API 扩展上级管理端点
- `admin-ui`: 用户编辑表单扩展上级选择

## 影响范围

| 影响点 | 说明 |
|--------|------|
| 用户模型 | 新增 manager_id 字段 |
| 用户 API | 新增上级管理端点 |
| 用户编辑表单 | 新增上级选择器 |
| 组织架构图 | 可展示汇报关系 |

### 后续依赖

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 循环引用导致无限递归 | 高 | 设置最大递归深度，提前检测 |
| 大规模组织上级链查询性能 | 中 | 缓存上级链，限制链深度 |
| 上级变更影响审批流程 | 中 | 提供变更确认提示 |
