# 提案：同步冲突解决策略

## 变更背景

当前同步服务中的冲突检测逻辑未实现，多设备同步时无法处理数据冲突。

## 冲突解决策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| Last-Write-Wins | 以时间戳最新为准 | 简单场景，数据重要性一致 |
| Server-Wins | 以服务器数据为准 | 数据安全性优先 |
| Client-Wins | 以客户端数据为准 | 离线工作场景 |
| Manual | 返回冲突由用户决定 | 重要数据，需要人工确认 |

## 变更目标

- 实现冲突检测机制
- 支持多种冲突解决策略
- 提供冲突回调接口

## 预期效果

- 多设备同步时可检测并解决冲突
- 支持灵活的配置策略
- 关键数据可人工介入
