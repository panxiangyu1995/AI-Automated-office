# 提案: 知识库RAG功能

## 1. 背景与问题

当前知识库CRUD基本完成，但RAG检索Pipeline未完整实现，无法支持智能问答场景。

## 2. 目标

实现完整的RAG检索Pipeline，支持向量检索+BM25混合检索，满足NFR8-2性能要求（<500ms）。

## 3. 覆盖需求

- FR14-4: 三层记忆架构（个人记忆、企业知识库、图记忆）
- FR251: 用户可以通过AI问答检索知识
- FR285: 系统支持向量语义检索
- FR286: 系统支持BM25关键词检索
- FR287: 系统采用RRF融合检索结果
- NFR8-2: 知识库混合检索响应时间 < 500ms

## 4. 预期效果

- 支持向量检索和BM25混合检索
- RRF算法融合检索结果
- 检索结果包含来源和相似度
- 性能满足NFR要求
