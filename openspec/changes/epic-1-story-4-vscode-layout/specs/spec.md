# Specification: 类VSCode四栏布局

## 需求来源

### PRD 需求
- **FR2**: 用户可以自定义调整界面面板大小和布局

### 架构约束
- **ADR-001**: 采用分层微内核架构

### UX 规范
- **UX-01**: 核心框架 React + TypeScript
- **UX-02**: 透明可控原则
- **UX-03**: 零学习成本原则
- **UX-04**: 即时价值原则

## 功能规格

### 用户故事
As a 用户,
I want 使用类 VSCode 风格的界面布局,
So that 界面简洁专业，功能区域清晰。

### 验收场景

#### Scenario 1: 四栏布局显示
- **GIVEN** 用户登录成功
- **WHEN** 进入主界面
- **THEN** 显示完整的四栏布局：
  - 活动栏（最左侧，48px 固定）
  - 侧边栏（200-280px，可折叠）
  - 工作区（自适应）
  - AI 对话面板（右侧，300-500px，可折叠）
- **AND** 各区域边界清晰
- **AND** 颜色符合设计规范

#### Scenario 2: 面板拖拽调整
- **GIVEN** 用户在主界面
- **WHEN** 拖拽面板边界
- **THEN** 面板大小实时调整
- **AND** 显示当前面板宽度
- **AND** 面板有最小/最大宽度限制

#### Scenario 3: 侧边栏折叠
- **GIVEN** 侧边栏展开
- **WHEN** 用户点击折叠按钮
- **THEN** 侧边栏收起
- **AND** 显示折叠动画
- **AND** 工作区自动扩展

#### Scenario 4: AI 面板折叠
- **GIVEN** AI 对话面板展开
- **WHEN** 用户点击折叠按钮
- **THEN** AI 面板收起
- **AND** 显示折叠动画
- **AND** 工作区自动扩展

#### Scenario 5: 布局持久化
- **GIVEN** 用户调整了布局
- **WHEN** 关闭并重新打开应用
- **THEN** 布局设置被保留
- **AND** 各面板宽度和折叠状态恢复

## 数据规格

### 布局配置
| 字段 | 类型 | 默认值 | 约束 |
|------|------|--------|------|
| sidebarWidth | number | 240 | 200-280 |
| chatPanelWidth | number | 400 | 300-500 |
| sidebarCollapsed | boolean | false | - |
| chatPanelCollapsed | boolean | false | - |

### 面板尺寸规格
| 区域 | 默认宽度 | 最小宽度 | 最大宽度 |
|------|---------|---------|---------|
| 活动栏 | 48px | 48px | 48px |
| 侧边栏 | 240px | 200px | 280px |
| 工作区 | 自适应 | 400px | - |
| AI 面板 | 400px | 300px | 500px |

## 边界条件

- 窗口最小宽度：1024px
- 窗口最小高度：600px
- 小屏幕时自动折叠侧边栏

## 错误处理

| 错误码 | 错误信息 | 处理方式 |
|--------|----------|----------|
| L001 | 布局配置加载失败 | 使用默认布局 |
| L002 | 面板宽度超出限制 | 自动调整到边界值 |

## 性能要求

| 指标 | 目标值 |
|------|--------|
| 面板拖拽响应 | < 16ms (60fps) |
| 折叠动画时长 | 200-300ms |
| 布局渲染时间 | < 100ms |
