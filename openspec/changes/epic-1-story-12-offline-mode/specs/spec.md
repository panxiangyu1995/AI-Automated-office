# Specification: 离线模式支持

## 需求来源

### PRD 需求
- **FR5**: 用户可以在离线状态下使用本地功能
- **ADR-003**: 数据存储采用本地优先 + 增量同步 + 智能冲突解决策略

## 功能规格

### 用户故事
As a 用户,
I want 在离线状态下使用本地功能,
So that 即使没有网络也能完成工作。

### 验收场景

#### Scenario 1: 离线模式启动
- **GIVEN** 用户已登录过一次
- **WHEN** 网络断开时打开应用
- **THEN** 显示离线模式提示
- **AND** 可以访问本地缓存的数据
- **AND** 可以使用本地功能（如查看历史对话）

#### Scenario 2: 数据自动同步
- **GIVEN** 用户在离线模式下操作
- **WHEN** 网络恢复
- **THEN** 自动同步离线期间的数据变更
- **AND** 显示同步进度

#### Scenario 3: 同步完成提示
- **GIVEN** 正在同步数据
- **WHEN** 同步完成
- **THEN** 显示"同步完成"提示
- **AND** 提示自动消失

## 数据规格

### 同步队列项
| 字段 | 类型 | 描述 |
|------|------|------|
| id | number | 主键 |
| entity_type | string | 实体类型 |
| entity_id | string | 实体 ID |
| action | string | 操作类型 (create/update/delete) |
| data | string | 数据 JSON |
| created_at | number | 创建时间戳 |

## 性能要求

| 指标 | 目标值 |
|------|--------|
| 网络状态检测延迟 | < 500ms |
| 本地操作响应 | < 100ms |
| 同步队列写入 | < 50ms |
