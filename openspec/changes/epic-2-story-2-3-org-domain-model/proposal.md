# Proposal: Department and Position Domain Model

## Why (背景与动机)

组织架构是企业人事管理的基础。Story 2.3 负责构建部门和岗位的数据模型和后端 API，为用户管理、权限分配等下游功能提供组织数据支撑。

部门采用树形结构，支持多级嵌套；岗位与部门关联，定义组织内的职能角色。

## What Changes (变更内容)

### 新增功能

1. **部门管理**
   - 部门树形结构存储和查询
   - 部门基本信息（名称、编码、负责人）
   - 部门层级关系（父子关系）
   - 删除和迁移约束

2. **岗位管理**
   - 岗位基本信息（名称、编码、描述）
   - 岗位与部门关联
   - 岗位权限预设

### 技术实现
- 在 Go 云端实现 RESTful API
- 部门使用 parent_id 实现树形结构
- 使用递归查询或闭包表优化树查询性能

## Capabilities 影响

### 新增 Capabilities
- `domain-model`: 组织架构数据模型和 API

### 修改 Capabilities
- 无（新增能力）
