# Specification: Frontend Login Flow

## 需求来源

### PRD 需求

**FR27 - 用户可以使用账号密码登录系统**

用户通过登录页面输入用户名和密码，系统验证通过后跳转到主界面。

**NFR9 - 数据传输加密**

所有网络传输使用 HTTPS，确保登录凭据安全传输。

**NFR12 - 会话管理**

登录成功后建立会话，会话状态由前端和云端共同管理。

### 架构约束

**ADR-001 - 分层微内核架构**
- 前端 React 负责登录交互和状态展示
- 认证状态存储在前端 Zustand Store
- Token 刷新由前端发起

### UX 规范

**UX-01 - AI 即入口**
- 登录页面作为系统入口之一
- 登录成功后进入 AI 对话主界面

**UX-04 - 零学习成本**
- 登录界面简洁明了
- 错误提示友好易懂
- 操作流程一目了然

## 功能规格

### 用户故事

As a **系统用户**,
I want **通过登录页面进入系统**,
So that **我可以使用 AI 助手和各部门功能**。

### 验收场景

#### Scenario 1: 成功登录
- **GIVEN** 用户在登录页面
- **AND** 输入正确的用户名和密码
- **WHEN** 点击登录按钮
- **THEN** 显示加载状态
- **AND** 登录成功后跳转到主界面
- **AND** 全局状态包含用户信息和权限

#### Scenario 2: 密码错误
- **GIVEN** 用户在登录页面
- **AND** 输入错误的密码
- **WHEN** 点击登录按钮
- **THEN** 显示错误提示"用户名或密码错误"
- **AND** 表单保持填写状态
- **AND** 可以重新尝试登录

#### Scenario 3: 账户锁定
- **GIVEN** 用户账户已被锁定
- **WHEN** 尝试登录
- **THEN** 显示错误提示"账户已被锁定，请稍后重试"
- **AND** 显示剩余锁定时间

#### Scenario 4: 表单验证失败
- **GIVEN** 用户在登录页面
- **AND** 用户名少于 3 个字符
- **WHEN** 点击登录按钮
- **THEN** 显示表单验证错误"用户名至少 3 个字符"
- **AND** 不发送登录请求

#### Scenario 5: 未认证访问受保护页面
- **GIVEN** 用户未登录
- **WHEN** 访问需要认证的页面
- **THEN** 重定向到登录页面
- **AND** 保存原始访问路径

#### Scenario 6: 登录后重定向
- **GIVEN** 用户从 /dashboard 被重定向到登录页
- **AND** 登录成功
- **THEN** 跳转到 /dashboard
- **AND** 不是默认首页

#### Scenario 7: 网络错误
- **GIVEN** 用户在登录页面
- **AND** 网络不可用
- **WHEN** 点击登录按钮
- **THEN** 显示错误提示"网络错误，请检查网络连接"
- **AND** 可以重新尝试登录

#### Scenario 8: 服务器错误
- **GIVEN** 用户在登录页面
- **AND** 服务器返回 500 错误
- **WHEN** 点击登录按钮
- **THEN** 显示错误提示"登录失败，请稍后重试"
- **AND** 可以重新尝试登录

## 数据规格

### 输入（用户输入）

| 字段 | 类型 | 必填 | 验证规则 | 描述 |
|------|------|------|----------|------|
| username | string | 是 | 3-50字符 | 用户名 |
| password | string | 是 | 8-100字符 | 密码 |

### 输出（状态存储）

| 字段 | 类型 | 描述 |
|------|------|------|
| user | object | 用户信息对象 |
| user.id | string | 用户 ID |
| user.username | string | 用户名 |
| user.email | string | 邮箱 |
| user.realName | string | 真实姓名 |
| user.departmentId | string | 部门 ID |
| user.positionId | string | 岗位 ID |
| user.status | string | 状态 |
| accessToken | string | 访问令牌 |
| refreshToken | string | 刷新令牌 |
| permissions | object | 权限摘要 |
| permissions.roles | string[] | 角色列表 |
| permissions.permissions | string[] | 权限列表 |
| permissions.dataScopes | object | 数据范围映射 |
| isAuthenticated | boolean | 是否已认证 |

## 边界条件

1. **用户名边界**: 3-50 字符，超出显示验证错误
2. **密码边界**: 8-100 字符，超出显示验证错误
3. **登录超时**: API 请求超时 10 秒
4. **并发登录**: 同一用户多设备登录（由后端处理）

## 错误处理

| 错误码 | 错误信息 | UI 显示 |
|--------|----------|---------|
| AUTH_001 | 用户名或密码错误 | 红色提示框 |
| AUTH_002 | 账户已被锁定 | 红色提示框 + 锁定图标 |
| AUTH_003 | 账户已禁用 | 红色提示框 + 禁用图标 |
| NETWORK_ERROR | 网络错误 | 红色提示框 |
| SERVER_ERROR | 服务器错误 | 红色提示框 |
| VALIDATION_ERROR | 表单验证失败 | 字段下方红色文字 |

## 质量属性

### 性能要求
- 登录页面加载时间 < 1s
- 表单交互响应 < 100ms
- API 请求超时 10s

### 可用性要求
- 表单字段支持 Tab 键切换
- 登录按钮支持 Enter 键提交
- 密码输入支持显示/隐藏切换

### 可访问性要求
- 所有表单元素有正确的 label
- 错误信息可被屏幕阅读器识别
- 颜色对比度符合 WCAG AA 标准
