## Context

当前 `AppLayout` 已经把右侧 AI 面板作为固定辅助侧栏挂在 Workbench 外侧，这符合铁律里“AI 是固定一级入口”的方向。但 `AiChatPanel -> SessionPanel` 这层又额外渲染了一个默认展开的左侧次级栏，用来承载会话列表与历史浏览，导致 AI 面板内部继续分裂为“工具导航 + 主内容”双栏结构。

这会带来三个问题：

1. 固定辅助侧栏内部再次形成常驻次级侧栏，压缩实际对话宽度，破坏对话优先。
2. 会话 / 历史这种频次较低的管理视图被长期占位，不符合“次级工具按需出现”的壳层职责。
3. TopBar `视图 / 助手` 菜单、布局按钮、设置页默认值、前端快捷键 hook 与 Tauri 默认快捷键没有统一来源，出现 `Ctrl+Shift+I` 与 `Ctrl+Shift+D` 分裂。

涉及模块横跨 shell、Agent 面板、设置页和 Tauri 快捷键注册，属于明确的跨模块交互重构，需要在编码前先固化设计决策。

## Goals / Non-Goals

**Goals:**

- 保留 AI 面板作为固定辅助侧栏，不改变工作台整体壳层拓扑。
- 将会话 / 历史管理改成 AI 面板中的按需次级视图，默认不常驻占位。
- 让 `新对话 / 打开历史 / 切换 AI 面板` 这些入口统一走一套壳层 UI 状态，而不是分散在多个本地状态和占位菜单里。
- 收敛 AI 面板快捷键默认值与展示文案，避免提示与真实行为脱节。
- 保持现有会话存储、历史筛选、归档恢复、staged review 机制不变。

**Non-Goals:**

- 不重做 TopBar、ActivityBar、Sidebar、Workbench 的整体布局。
- 不改变聊天消息、会话数据模型、历史筛选规则和 staged review 业务语义。
- 不为历史浏览新增独立全局快捷键，本次仍以面板内入口和 TopBar 入口为主。
- 不扩展新的 Agent 能力范围，只重构壳层交互与入口一致性。

## Decisions

### 1. 把 AI 面板次级视图状态提升到 `uiStore`

新增 UI-only 状态，例如 `agentSecondarySurface: 'none' | 'sessions' | 'history'`，并提供统一的打开 / 关闭动作。  
原因：会话 / 历史的打开请求会来自 `TopBar`、AI 面板头部动作、布局控制以及后续可能的命令入口，本地组件状态会让这些入口继续分裂。

备选方案：

- 继续使用 `SessionPanel` 本地状态，再通过自定义事件触发。
  - 放弃原因：事件链路隐式、可测性差，而且会重复实现“自动展开 AI 面板后再打开次级视图”的逻辑。

### 2. 保留 AI 面板固定位置，但把会话 / 历史改为内部覆盖式次级视图

`SessionPanel` 继续作为 AI 面板容器，但其主层永远是 `AgentChatPanel`。会话列表和历史浏览以覆盖式抽屉 / sheet 出现在 AI 面板内部，打开时压住聊天区，关闭后完全回到 chat-first 状态。

原因：

- 这符合铁律里的固定壳层和 AI 一级入口，同时把低频管理视图降级为按需工具。
- 与全屏 Dialog 相比，AI 面板内覆盖层更能保留“仍在同一辅助侧栏内工作”的空间语义。

备选方案：

- 维持现有双栏结构，但默认折叠次级侧栏。
  - 放弃原因：虽然默认不展开，但交互心智仍然是“AI 面板里有一条长期存在的次级栏”，没有真正解决层级问题。
- 使用全局 Dialog / 全屏抽屉承载会话和历史。
  - 放弃原因：会把次级工具升级成全局模态，破坏固定辅助侧栏的边界。

### 3. Agent 入口动作必须做实，不再保留壳层占位菜单

TopBar 的 `视图 -> AI 对话面板`、`助手 -> 新对话`、`助手 -> 历史记录` 必须分别驱动：

- AI 面板展开 / 收起
- 自动创建新会话并确保 AI 面板可见
- 打开历史次级视图并确保 AI 面板可见

原因：发现性入口本来就属于固定壳层职责，不能继续停留在 `console.log` 级别的假动作。

### 4. 快捷键默认值改为单一来源，并让展示文案引用同一份数据

创建共享的快捷键默认值 / 读取辅助模块，由前端 hook、设置页、TopBar 文案和测试共同使用；Tauri 侧的默认注册同步收敛到 `CmdOrCtrl+Shift+I`。

原因：当前默认值在多个文件复制，才导致文案和行为分裂。  
兼容策略：已保存的自定义快捷键继续保留；未显式自定义的默认值与重置默认动作统一改到 `Ctrl+Shift+I`。

## Risks / Trade-offs

- [次级视图覆盖聊天区后，用户可能误以为离开当前对话] → 通过保持 AI 面板头部标题、加明显关闭动作、选择后自动回到当前会话来减轻认知跳跃。
- [壳层状态提升到 `uiStore` 后，若动作定义不清晰容易和面板折叠状态互相打架] → 只保留最小枚举状态与显式 helper，避免派生状态散落在组件内。
- [快捷键默认值收敛可能让已有旧默认用户感知变化] → 设置页明确展示当前实际值，TopBar 提示引用真实当前值而不是硬编码文案。

## Migration Plan

1. 新增统一快捷键默认值模块与 AI 面板次级视图状态。
2. 重构 `SessionPanel` / `AgentChatPanel` 为 chat-first + on-demand secondary surface。
3. 打通 TopBar、布局按钮、设置页和快捷键默认值引用。
4. 更新 Vitest 与 Playwright 覆盖，完成 lint / build / smoke 验证。

回滚策略：若次级视图交互引入不可接受回归，可回退到旧版 `SessionPanel` 双栏实现，并恢复原快捷键默认常量与 TopBar 入口行为。

## Open Questions

- 暂无阻塞性开放问题。本次按“历史 / 会话只提供面板内入口和 TopBar 入口，不新增专属全局快捷键”执行。
