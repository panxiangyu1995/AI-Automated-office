# Specification: 工具权限沙箱实现

## 需求来源

### PRD 需求
- FR1020: 工具权限配置
- FR1021: 黑名单管理
- FR1022: 白名单管理
- FR1023: 执行隔离
- FR1024: 敏感操作告警

### 架构约束
- ADR-022: 黑名单采用简单通配符模式
- ADR-022-1: 命令黑白名单采用三层机制
- ADR-052: 三级动作模型（ask/allow/deny）

## 功能规格

### 三层机制

| 层 | 动作 | 描述 |
|----|------|------|
| 黑名单 | DENY | 禁止执行 |
| 灰名单 | ASK | 需用户确认 |
| 白名单 | ALLOW | 允许执行（可选） |

### 匹配模式

| 模式 | 描述 |
|------|------|
| Exact | 精确匹配 |
| Prefix | 前缀匹配 |
| Suffix | 后缀匹配 |
| Contains | 包含匹配 |
| Regex | 正则表达式 |
| Group | 分组匹配 |

## 验收场景

### Scenario 1: 黑名单阻止
- **GIVEN** rm -rf在黑名单中
- **WHEN** 工具执行rm -rf /
- **THEN** 命令被阻止，返回权限错误

### Scenario 2: 灰名单需确认
- **GIVEN** delete_*在灰名单中
- **WHEN** 工具执行delete_file
- **THEN** 返回ASK状态，前端显示确认对话框
