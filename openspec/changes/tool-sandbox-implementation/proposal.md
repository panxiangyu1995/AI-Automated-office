# Proposal: 工具权限沙箱实现

## 变更类型
- [x] 新功能
- [ ] 重构
- [ ] 优化
- [ ] 开发

## 背景

当前权限中间件已存在 (`src-tauri/src/agent/permission/`)：
- `middleware.rs` - 权限中间件
- `engine.rs` - 权限引擎
- `scope_filter.rs` - 作用域过滤器
- `field_checker.rs` - 字段检查器

**缺失部分**：命令黑白名单、执行隔离、敏感操作告警。

## 目标

实现工具权限沙箱 (FR1020-FR1027)：
1. 命令黑名单匹配引擎
2. 命令白名单机制
3. 灰名单需确认模式
4. 工具执行隔离
5. 敏感操作告警
6. 权限审计日志

## 影响范围

### 前端
- 新增沙箱配置 UI（可选）

### 后端
- `src-tauri/src/agent/permission/` - 扩展现有模块
- `src-tauri/src/agent/tools/sandbox.rs` - 新增沙箱执行器

## 风险评估

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 误判导致合法操作被阻止 | 中 | 中 | 提供白名单和申诉机制 |
| 性能影响 | 低 | 低 | 异步执行 |

## 依赖

- **前置依赖**: Task 157 (Agent E2E集成测试)
- **后置依赖**: Task 165 (MVP最终集成测试)

## 验收标准

1. 黑名单命令被正确拦截
2. 白名单命令被直接执行
3. 灰名单命令需要用户确认
4. 执行日志完整记录
