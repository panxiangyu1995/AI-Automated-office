## 背景

统一消息通知系统是MVP的核心功能之一，用于向用户推送系统公告、新消息提醒、待办通知等。PRD明确要求系统公告、消息推送、未读提醒、免打扰模式。

## 目标

实现统一消息通知系统：
1. 消息数据模型和存储
2. 消息发送和订阅
3. 未读计数和提醒
4. 免打扰模式
5. 消息管理 UI
