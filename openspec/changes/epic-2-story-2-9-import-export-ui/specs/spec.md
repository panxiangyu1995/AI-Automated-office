# Specification: Import and Export UI

## 需求来源

### PRD 需求

**FR33 - 管理员可以导入和导出用户数据**

管理员通过前端界面完成用户数据的批量导入和导出操作。

### 架构约束

**ADR-001 - 分层微内核架构**
- UI 逻辑位于 Presentation Layer
- 前端 React 负责用户交互

### UX 规范

**UX-02**: 使用 Shadcn/ui 组件库
**UX-04**: 交互透明可控，错误提示清晰

## 功能规格

### 用户故事

As a **管理员**,
I want **通过直观的界面批量导入和导出用户数据**,
So that **我能高效管理大量用户信息**。

### 验收场景

#### Scenario 1: 下载导入模板
- **GIVEN** 管理员进入导入导出页面
- **WHEN** 管理员点击下载模板
- **THEN** 系统下载标准 Excel 模板
  - 文件名包含日期
  - 包含字段说明 sheet

#### Scenario 2: 上传文件并预览
- **GIVEN** 管理员准备了导入文件
- **WHEN** 管理员上传文件
- **THEN** 系统显示预览数据
  - 显示统计信息
  - 显示冲突列表（如有）
  - 显示错误列表（如有）

#### Scenario 3: 处理冲突数据
- **GIVEN** 预览中存在冲突数据
- **WHEN** 管理员查看冲突列表
- **THEN** 显示每行冲突的详情
  - 行号、字段、值、冲突类型
  - 处理建议

#### Scenario 4: 确认导入
- **GIVEN** 预览数据已展示
- **WHEN** 管理员选择冲突处理模式并确认
- **THEN** 系统开始导入
  - 显示处理进度
  - 完成后显示结果

#### Scenario 5: 查看导入结果
- **GIVEN** 导入完成
- **WHEN** 查看结果页面
- **THEN** 显示导入统计
  - 成功数、失败数
  - 失败详情（如有）
  - 回执下载按钮

#### Scenario 6: 下载结果回执
- **GIVEN** 导入已完成
- **WHEN** 管理员点击下载回执
- **THEN** 系统下载结果回执文件
  - 包含导入概览
  - 包含失败详情

#### Scenario 7: 导出全部用户
- **GIVEN** 管理员进入导出 tab
- **WHEN** 选择导出全部用户并点击导出
- **THEN** 系统下载用户数据 Excel
  - 包含所有字段
  - 包含所有用户

#### Scenario 8: 导出指定部门用户
- **GIVEN** 管理员进入导出 tab
- **WHEN** 选择按部门导出并选择部门
- **THEN** 系统下载该部门用户数据

#### Scenario 9: 选择导出字段
- **GIVEN** 管理员进入导出 tab
- **WHEN** 管理员选择部分字段并导出
- **THEN** 导出文件只包含选中字段

#### Scenario 10: 文件上传失败
- **GIVEN** 管理员上传格式错误的文件
- **WHEN** 系统检测到错误
- **THEN** 显示错误提示
  - 说明错误原因
  - 提供解决建议

## 数据规格

### 输入

| 输入 | 类型 | 描述 |
|------|------|------|
| 文件 | File | Excel 文件（.xlsx） |
| 冲突处理模式 | string | skip/update/error |
| 导出范围 | string | all/department/filter |
| 导出字段 | string[] | 选中的字段列表 |

### 输出

| 输出 | 类型 | 描述 |
|------|------|------|
| 预览数据 | object | 统计、冲突、错误列表 |
| 导入结果 | object | 成功/失败统计 |
| 导出文件 | File | Excel 文件 |

## 边界条件

1. **文件格式**: 仅支持 .xlsx
2. **文件大小**: 最大 10MB
3. **导出数量**: 单次最大 10000 条

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 文件格式错误 | 显示提示，要求使用 .xlsx 格式 |
| 文件过大 | 显示提示，要求拆分文件 |
| 上传失败 | 显示错误信息，提供重试按钮 |
| 导出失败 | 显示错误信息，提供重试按钮 |

## 质量属性

### 可用性要求
- 步骤化引导清晰
- 错误提示可操作
- 支持键盘导航

### 性能要求
- 文件上传显示进度
- 大文件预览 < 5秒
- 导出生成 < 10秒

### 可访问性要求
- 颜色对比度符合 WCAG AA
- 支持屏幕阅读器
- 键盘可操作

## 依赖关系

### 上游依赖
- E2-S2.9-01: Import preview and conflict detection
- E2-S2.9-02: Import commit and receipt

### API 依赖
- `GET /api/admin/users/import/template` - 下载模板
- `POST /api/admin/users/import/preview` - 上传预览
- `POST /api/admin/users/import/commit` - 确认导入
- `GET /api/admin/users/import/batches/:id/receipt` - 下载回执
- `POST /api/admin/users/export` - 导出用户

## 验收标准

| 标准 | 验证方式 |
|------|---------|
| 导入流程正常 | E2E 测试 |
| 导出流程正常 | E2E 测试 |
| 错误处理正确 | 手动测试 |
| UI 交互流畅 | 手动测试 |
| 无控制台错误 | 手动检查 |
