# Proposal: Department and Position UI

## Why (背景与动机)

组织架构管理是人事管理的基础功能。Story 2.3 的后端 API 已在 E2-S2.3-01 中实现。本变更负责构建部门和岗位管理的前端界面，为管理员提供可视化的组织架构管理入口。

部门管理需要树形视图，支持展开/折叠、拖拽排序等交互；岗位管理需要列表视图，支持筛选和批量操作。

## What Changes (变更内容)

### 新增页面
1. **组织管理入口页** (`/admin/organization`)
   - 左侧：部门树面板
   - 右侧：岗位列表或部门详情

2. **部门树管理**
   - 树形结构展示
   - 节点展开/折叠
   - 右键菜单操作
   - 拖拽排序（可选）

3. **岗位列表管理**
   - 岗位数据表格
   - 创建/编辑岗位表单
   - 删除确认对话框

### UI 组件
- DepartmentTree: 部门树组件
- DepartmentNode: 部门节点组件
- DepartmentForm: 部门表单组件
- PositionTable: 岗位表格组件
- PositionForm: 岗位表单组件

## Capabilities 影响

### 新增 Capabilities
- `ui`: 组织管理前端界面

### 修改 Capabilities
- 无

## 影响范围

| 影响点 | 说明 |
|--------|------|
| React 前端 | 新增组织管理相关页面和组件 |
| 路由配置 | 新增组织管理路由 |
| 状态管理 | 可能需要新增组织数据缓存 |

## 依赖分析

### 前置依赖
- **E2-S2.3-01**: Department and position domain model（后端 API）

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 大规模部门树渲染性能 | 中 | 虚拟滚动或懒加载 |
| 拖拽排序复杂 | 低 | MVP 可不实现拖拽 |
| 树状态管理复杂 | 中 | 使用现有树组件库 |

## 时间估算
- 设计与评审: 0.5 天

- 测试与修复: 0.5 天
- **总计**: 3-4 天
