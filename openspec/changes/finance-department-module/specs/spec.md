# Specification: Finance财务部门模块

## 需求来源
- FR160: 用户可以上传发票进行OCR识别
- FR161: AI可以提取发票信息
- FR162: 用户可以生成台账
- FR163: 系统可以自动匹配发票和销售数据
- FR164: 用户可以查看应收应付报表
- FR165: AI可以辅助对账

## 验收场景
### Scenario 1: 发票OCR识别
- **GIVEN** 用户上传发票图片
- **WHEN** 系统进行OCR识别
- **THEN** 显示识别结果供确认

### Scenario 2: 与销售联动
- **GIVEN** 财务审核发票
- **WHEN** 查看关联的销售数据
- **THEN** 显示关联的报价单和合同信息
