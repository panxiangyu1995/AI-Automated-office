# Proposal: Dynamic Card Layout for Workbench Content

## Background
Upgrade home and department workbench content areas to dynamic card layout.

## Scope
### In Scope
- Define card layout contract
- Render chart and todo cards
- Render quick entry sections
- Load workbench content configuration

### Out of Scope
- Full low-code designer UX in this story
- Cross-tenant behavior changes

## Risks
- Regression in fixed UI route behavior
- Permission boundary drift in dynamic rendering

## Dependencies
- Story 42.3
