## Technical Approach

### 权限反馈架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    前端权限反馈架构                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 路由级权限守卫                                              │
│     ├── 检查路由所需权限                                        │
│     └── 无权限时跳转 403 页面或显示空状态                       │
│                                                                 │
│  2. 组件级权限守卫                                              │
│     ├── PermissionGuard 组件                                    │
│     ├── 无权限时隐藏/禁用/显示空状态                            │
│     └── 支持按钮级权限控制                                      │
│                                                                 │
│  3. 403 响应处理                                                │
│     ├── 全局拦截 403 响应                                       │
│     ├── 显示拒绝原因和所需权限                                  │
│     └── 提供申请入口                                            │
│                                                                 │
│  4. 申请权限流程                                                │
│     ├── 显示权限申请弹窗                                        │
│     ├── 填写申请原因                                            │
│     └── 提交审批                                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 组件清单

| 组件名 | 用途 | 使用场景 |
|--------|------|---------|
| ForbiddenPage | 403 专用页面 | 路由守卫重定向 |
| NoPermissionEmpty | 无权限空状态 | 列表页无权限 |
| PermissionGuard | 权限守卫组件 | 按钮级权限控制 |
| ForbiddenModal | 权限拒绝弹窗 | 403 响应拦截 |
| ApplyPermissionModal | 申请权限弹窗 | 申请入口点击 |
