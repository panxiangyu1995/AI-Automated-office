# Proposal: 向量数据库初始化

## Story 1.9

**Epic:** Epic 1 - 基础设施与桌面端框架
**Phase:** Phase 1.2 - 核心基础设施

## 背景

知识库RAG系统需要向量检索能力。根据架构设计（ADR-014），MVP阶段实现向量+BM25混合搜索。需要初始化向量数据库支持本地和云端两种部署模式。

## 问题陈述

- 知识库RAG无法工作（缺少向量存储）
- 记忆系统语义检索无法实现
- 混合搜索（向量+BM25）无法实现

## 提议方案

创建向量数据库支持：

1. **本地模式**: sqlite-vec（嵌入式向量存储）
2. **云端模式**: Qdrant HTTP API
3. **向量嵌入**: OpenAI兼容格式
4. **混合搜索**: 向量+BM25+RRF融合

## 覆盖需求

- **FR**: FR14-8, FR14-11（记忆系统）, FR250-FR254（知识库RAG）
- **NFR**: NFR8-1, NFR8-2（检索性能）, NFR28-3（向量数据库）

## 依赖关系

- **前置依赖**: Story 1.8（SQLite）
- **被依赖**: Epic 6（记忆层系统）, Epic 9（知识库RAG）
