# 前后端通信架构

**Story 1.10** | Epic 1 - 基础设施与桌面端框架

## 概述

建立前后端通信架构，使Tauri桌面端可以与云端服务通信。

## 铁律映射

| 铁律文档 | 映射内容 |
|----------|----------|
| **PRD** | FR9 AI对话, FR44 消息通知, FR46 任务通知 |
| **架构** | ADR-004 通信架构 |
| **UX** | 无直接映射（后端基础设施） |
| **Epic** | Epic 1, Story 1.10 |

## 验收标准

- [ ] REST API客户端封装完成
- [ ] WebSocket实时通信正常
- [ ] 请求拦截器（Token注入）工作正常
- [ ] 响应拦截器（错误处理、Token刷新）工作正常
- [ ] 离线请求队列可用
- [ ] 网络状态监控可用

## 依赖关系

```

Story 1.10 (通信架构)
```

## 通信架构

```
┌─────────────────────────────────────────────────┐
│              Tauri Desktop App                   │
│  ┌───────────┐         ┌───────────────────┐   │
│  │  React    │ ← IPC → │  Rust Backend     │   │
│  │  前端     │         │  HTTP Client      │   │
│  └───────────┘         └───────────────────┘   │
│         │                       │               │
│         └─── 离线队列 (SQLite) ──┘              │
└─────────────────────────────────────────────────┘
                    │
           HTTPS / WebSocket
                    ↓
┌─────────────────────────────────────────────────┐
│              Go Cloud Server                     │
│  REST API :8080    WebSocket :8080/ws           │
└─────────────────────────────────────────────────┘
```
