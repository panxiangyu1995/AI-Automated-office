## Context

现有 Epic 1 中的全局快捷键与后续 Agent 配置需要统一的设置入口与承载页面，但当前缺少基础设置框架与持久化策略，导致配置能力不可交付。项目为 Tauri + React + TypeScript 桌面端，需与现有 TopBar 菜单与布局保持一致。

## Goals / Non-Goals

**Goals:**
- 提供统一设置入口与基础页面框架
- 建立通用/快捷键/Agent/更新分区的导航与布局结构
- 支持设置项持久化与恢复默认
- 为 Story 1.3 全局快捷键配置提供可用承载

**Non-Goals:**
- 不在本故事内实现完整的 Agent 配置细节
- 不在本故事内实现更新策略与安装流程
- 不引入新的权限或多租户设置策略

## Decisions

- 使用现有 TopBar 的设置入口打开设置页面，保持布局风格统一并降低学习成本
- 设置页面采用四分区基础结构，后续能力以分区插件化扩展，避免一次性堆叠
- 设置项持久化使用本地存储与配置文件同步，确保离线可用
- 快捷键修改即刻生效，并提供恢复默认策略，减少误操作成本

## Risks / Trade-offs

- 设置页面范围扩大可能与后续模块冲突 → 通过分区扩展机制与路由隔离减轻冲突
- 持久化策略不统一导致配置散落 → 定义统一设置存储接口与键命名规范
- 快捷键生效与系统热键冲突 → 提供冲突提示与回退默认选项

## Migration Plan

- 新增设置入口不影响现有功能，默认为空配置
- 更新后首次进入设置页面时写入默认配置
- 如需回滚，仅移除设置入口与页面路由即可
