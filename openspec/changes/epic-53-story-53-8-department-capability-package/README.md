# 部门能力包系统 - 注册机制与市场

## 概述

本变更实现部门能力包系统的核心功能，包括能力包注册机制、市场系统、版本管理和权限控制。

## 当前状态

**缺失功能**:
- 能力包注册机制缺失
- 部门能力包市场缺失
- 能力包版本管理缺失
- 能力包权限控制缺失
- 能力包依赖管理缺失

## 目标

1. 实现能力包注册机制
2. 建立部门能力包市场
3. 支持版本管理与发布
4. 实现权限与访问控制
5. 支持依赖管理与冲突解决

## 功能需求覆盖

| FR编号 | 功能描述 | 实现文件 |
|--------|----------|----------|
| FR800 | 能力包注册机制 | `registry.rs` |
| FR801 | 部门能力包市场 | `marketplace.rs` |
| FR802 | 版本管理 | `version.rs` |
| FR803 | 权限控制 | `permission.rs` |
| FR804 | 依赖管理 | `dependency.rs` |

## 核心部门能力包

| 部门 | 能力包ID | 描述 |
|------|----------|------|
| 人事部 | `hr-capability` | 员工管理、考勤、薪资 |
| 审批中心 | `approval-capability` | 审批流程、表单处理 |
| 销售部 | `sales-capability` | 客户管理、合同、报价 |
| 财务部 | `finance-capability` | 账务、报销、预算 |
| 仓储部 | `warehouse-capability` | 库存、出入库、盘点 |
| 管理层 | `management-capability` | 决策支持、报表 |

## 扩展部门能力包

| 部门 | 能力包ID | 描述 |
|------|----------|------|
| 售后服务 | `aftersales-capability` | 工单、客户反馈 |
| 招投标 | `bidding-capability` | 标书、投标管理 |
| 市场宣传 | `marketing-capability` | 活动管理、推广 |
