## 背景

根据 UX 设计规范，L3 多标签页需要支持键盘快捷键操作：

> - `Ctrl+Tab` — 切换到下一个 Tab
> - `Ctrl+Shift+Tab` — 切换到上一个 Tab
> - `Ctrl+W` — 关闭当前 Tab
> - `Ctrl+T` — 新建 Tab
> - `Ctrl+1~9` — 切换到第 N 个 Tab

## 目标

实现 Tab 键盘快捷键支持，提升用户操作效率。

## 范围

### 包含

- 全局键盘事件监听
- Tab 快捷键处理
- 快捷键覆盖检测
- 快捷键冲突提示

### 不包含

- 自定义快捷键配置（后续版本）
- 快捷键录制功能

## 影响范围

### 前端

- 修改 `src/components/common/TabBar.tsx` — 添加快捷键处理
- 修改 `src/hooks/useGlobalShortcuts.ts` — 添加 Tab 快捷键
- 新增快捷键处理 hook

### 后端

- 无
