## Planned Steps
1. Create user override page (用户权限覆盖页面)
2. Show inherited role permissions versus user overrides (展示继承权限与覆盖对比)
3. Configure data scopes and field-level restrictions (配置数据范围和字段限制)
4. Add confirmation and explanation UI (添加确认和说明 UI)

## Technical Approach

### 页面结构

```
┌─────────────────────────────────────────────────────────────────┐
│                    细粒度权限配置页面布局                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  顶部导航栏                                                     │
│  ├── 用户选择器（搜索选择用户）                                 │
│  ├── 用户基本信息展示                                           │
│  └── 当前角色和权限摘要                                         │
│                                                                 │
│  主内容区                                                       │
│  ├── Tab 1: 权限覆盖配置                                        │
│  │   ├── 资源列表（按模块分组）                                 │
│  │   ├── 权限覆盖操作（授权/剥夺）                              │
│  │   └── 权限来源对比展示                                       │
│  │                                                              │
│  ├── Tab 2: 数据范围配置                                        │
│  │   ├── 资源选择                                               │
│  │   ├── 数据范围类型选择                                       │
│  │   └── 自定义规则编辑器                                       │
│  │                                                              │
│  └── Tab 3: 字段权限配置                                        │
│      ├── 资源选择                                               │
│      ├── 字段列表                                               │
│      └── 字段权限设置（可见/隐藏/只读/脱敏）                    │
│                                                                 │
│  底部操作栏                                                     │
│  ├── 保存按钮                                                   │
│  └── 重置按钮                                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
