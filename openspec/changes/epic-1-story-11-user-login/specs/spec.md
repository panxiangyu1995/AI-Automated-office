# Specification: 用户登录功能

## 需求来源

### PRD 需求
- **FR1**: 用户可以通过桌面应用登录系统
- **FR27**: 用户可以使用账号密码登录系统
- **FR28**: 管理员可以创建和编辑用户账号
- **NFR9**: 数据传输加密 TLS 1.3
- **NFR11**: 密码 bcrypt 加密存储，强度因子 >= 12
- **NFR12**: 会话超时 30 分钟

### UX 规范
- **UX-01**: 核心框架 React + TypeScript
- **UX-04**: 即时价值原则

## 功能规格

### 用户故事
As a 用户,
I want 通过 Go 云端认证接口完成登录、注册和忘记密码请求,
So that 可以在统一认证服务下访问个人工作空间。

### 验收场景

#### Scenario 1: 登录界面显示
- **GIVEN** 用户打开应用
- **WHEN** 应用启动完成
- **THEN** 显示登录界面
- **AND** 包含账号输入框
- **AND** 包含密码输入框
- **AND** 包含"记住我"复选框
- **AND** 包含"忘记密码"链接
- **AND** 包含登录按钮

#### Scenario 2: 登录成功
- **GIVEN** 用户在登录界面
- **AND** 输入正确的账号和密码
- **WHEN** 点击登录按钮
- **THEN** 显示加载状态
- **AND** 登录成功后跳转到主界面
- **AND** 会话信息保存到本地

#### Scenario 3: 登录失败
- **GIVEN** 用户在登录界面
- **AND** 输入错误的账号或密码
- **WHEN** 点击登录按钮
- **THEN** 显示"账号或密码错误"提示
- **AND** 可重新尝试登录

#### Scenario 4: 注册成功
- **GIVEN** 用户在注册模式
- **AND** 输入合法用户名、密码和姓名
- **WHEN** 点击注册按钮
- **THEN** 请求 `/api/v1/auth/register`
- **AND** 返回成功后切换回登录模式
- **AND** 显示注册成功提示

#### Scenario 5: 忘记密码请求
- **GIVEN** 用户在登录模式
- **AND** 已输入账号
- **WHEN** 点击忘记密码
- **THEN** 请求 `/api/v1/auth/forgot-password`
- **AND** 显示受理结果提示

#### Scenario 6: 记住我功能
- **GIVEN** 用户勾选"记住我"
- **WHEN** 登录成功并关闭应用
- **THEN** 下次打开应用时自动登录
- **AND** 直接进入主界面

#### Scenario 7: 会话超时
- **GIVEN** 用户已登录
- **AND** 会话超过 30 分钟无活动
- **WHEN** 用户尝试操作
- **THEN** 自动登出
- **AND** 显示"会话已过期"提示
- **AND** 跳转到登录页面

## 数据规格

### 登录请求
| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| username | string | 是 | 非空，长度 3-50 |
| password | string | 是 | 非空，长度 6-100 |
| rememberMe | boolean | 否 | 默认 false |

### 注册请求
| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| username | string | 是 | 非空，长度 3-50 |
| password | string | 是 | 非空，长度 6-100 |
| name | string | 是 | 非空 |
| department | string | 否 | 非空时存储部门信息 |

### 忘记密码请求
| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| username | string | 是 | 非空 |

### 登录响应
| 字段 | 类型 | 描述 |
|------|------|------|
| user | object | 用户信息 |
| token | string | 认证令牌 |

## 安全要求

| 要求 | 实现 |
|------|------|
| 密码传输加密 | TLS 1.3 |
| 密码存储加密 | 云端 bcrypt |
| Token 有效期 | 云端 JWT 配置控制 |
| Token 存储 | 系统安全存储 |

## 性能要求

| 指标 | 目标值 |
|------|--------|
| 登录响应时间 | < 3 秒 |
| 本地验证时间 | < 100ms |
