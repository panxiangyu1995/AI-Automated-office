# Tasks: 系统托盘集成

## 任务列表

### 任务 1: 启用 Tauri Tray 特性
- **描述**: 在 Cargo.toml 中启用 tray-icon 特性
- **文件**: `src-tauri/Cargo.toml`
- **验收**: Rust 编译成功

### 任务 2: 创建托盘图标资源
- **描述**: 创建多格式托盘图标（PNG、ICO）
- **文件**: `assets/icons/tray-icon.*`
- **验收**: 图标在各系统正常显示

### 任务 3: 实现托盘模块
- **描述**: 创建 Rust 托盘模块，处理托盘初始化和事件
- **文件**: `src-tauri/src/tray.rs`
- **验收**: 托盘图标正常显示

### 任务 4: 实现托盘菜单
- **描述**: 实现右键菜单（显示窗口、设置、退出）
- **文件**: `src-tauri/src/tray.rs`
- **验收**: 右键菜单正常显示和响应

### 任务 5: 实现单击唤起
- **描述**: 实现单击托盘图标唤起窗口
- **文件**: `src-tauri/src/tray.rs`
- **验收**: 单击响应时间 < 500ms

### 任务 6: 实现最小化到托盘
- **描述**: 窗口关闭时最小化到托盘而非退出
- **文件**: `src-tauri/src/main.rs`, `src/App.tsx`
- **验收**: 关闭窗口后应用仍在托盘运行

### 任务 7: 创建前端托盘 Hook
- **描述**: 创建 useTray Hook 监听托盘事件
- **文件**: `src/hooks/useTray.ts`
- **验收**: 前端可响应托盘事件

### 任务 8: 更新配置
- **描述**: 更新 tauri.conf.json 配置托盘相关设置
- **文件**: `src-tauri/tauri.conf.json`
- **验收**: 配置生效

## 执行顺序

1. 任务 1 → 任务 2（准备资源和依赖）
2. 任务 3 → 任务 4 → 任务 5（核心功能）
