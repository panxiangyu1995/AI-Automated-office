# 向量数据库初始化

**Story 1.9** | Epic 1 - 基础设施与桌面端框架

## 概述

初始化向量数据库支持，为知识库RAG、记忆层系统提供向量检索能力。

## 铁律映射

| 铁律文档 | 映射内容 |
|----------|----------|
| **PRD** | FR14-8, FR14-11 记忆层, FR250-FR254 知识库RAG |
| **架构** | ADR-014 混合搜索架构（向量+BM25+RRF） |
| **UX** | 无直接映射（后端基础设施） |
| **Epic** | Epic 1, Story 1.9 |

## 验收标准

- [ ] 向量存储抽象接口定义完成
- [ ] sqlite-vec 本地存储实现
- [ ] Qdrant 云端适配器实现
- [ ] 向量嵌入服务可调用
- [ ] 混合搜索（向量+BM25）正常工作
- [ ] RRF 融合算法实现

## 技术方案

### 部署模式

| 模式 | 实现 | 适用场景 |
|------|------|----------|
| 本地模式 | sqlite-vec | 离线使用、小规模数据 |
| 云端模式 | Qdrant | 大规模、企业级 |

### 混合搜索架构 (ADR-014)

```
Query
  ├── 向量搜索 → 向量结果
  └── BM25搜索 → BM25结果
            ↓
      RRF融合
            ↓
       最终结果
```
