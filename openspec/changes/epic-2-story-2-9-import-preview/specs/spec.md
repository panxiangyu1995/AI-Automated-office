# Specification: Import Preview and Conflict Detection

## 需求来源

### PRD 需求

**FR33 - 管理员可以导入和导出用户数据**

管理员可以批量导入用户数据，系统在导入前提供预览和冲突检测功能，确保数据准确性。

**FR33 补充说明 - 管理员可通过 Excel 批量导入员工信息（导入预览阶段）**

### 架构约束

**ADR-005 - 多租户数据库级隔离**
- 导入数据需遵循租户隔离原则
- 冲突检测仅限当前租户范围内

### NFR 约束

**NFR16 - 数据完整性**
- 导入数据需进行完整性和一致性校验
- 错误数据不写入数据库

## 功能规格

### 用户故事

As a **管理员**,
I want **在批量导入用户前预览数据和检测冲突**,
So that **我能确保导入数据的准确性和一致性**。

### 验收场景

#### Scenario 1: 下载导入模板
- **GIVEN** 管理员已登录系统
- **WHEN** 管理员点击下载导入模板
- **THEN** 系统返回标准 Excel 模板
  - 包含所有支持的字段
  - 必填字段有标注
  - 包含示例数据行
  - 包含字段说明 sheet

#### Scenario 2: 上传有效文件预览
- **GIVEN** 管理员准备了有效的导入文件
- **WHEN** 管理员上传文件并请求预览
- **THEN** 系统返回预览数据
  - 显示总行数
  - 显示可导入行数
  - 显示冲突行数
  - 显示错误行数
  - 返回解析后的数据列表

#### Scenario 3: 检测用户名重复
- **GIVEN** 导入文件中存在与现有用户重复的用户名
- **WHEN** 系统进行冲突检测
- **THEN** 返回冲突报告
  - 标记冲突行号
  - 显示重复的用户名
  - 提供处理建议（更新现有用户/使用新用户名）

#### Scenario 4: 检测工号重复
- **GIVEN** 导入文件中存在与现有用户重复的工号
- **WHEN** 系统进行冲突检测
- **THEN** 返回冲突报告
  - 标记冲突行号
  - 显示重复的工号
  - 提供处理建议

#### Scenario 5: 检测部门不存在
- **GIVEN** 导入文件中包含不存在的部门名称
- **WHEN** 系统进行冲突检测
- **THEN** 返回冲突报告
  - 标记冲突行号
  - 显示不存在的部门名称
  - 提供处理建议（创建新部门/选择现有部门）

#### Scenario 6: 检测必填字段缺失
- **GIVEN** 导入文件中某行缺少必填字段
- **WHEN** 系统进行数据验证
- **THEN** 返回错误报告
  - 标记错误行号
  - 显示缺失的字段名
  - 要求补充数据

#### Scenario 7: 检测格式错误
- **GIVEN** 导入文件中存在格式错误的数据（如邮箱格式无效）
- **WHEN** 系统进行数据验证
- **THEN** 返回错误报告
  - 标记错误行号
  - 显示错误字段和值
  - 显示格式要求

#### Scenario 8: 预览数据过期
- **GIVEN** 管理员已获取预览数据
- **WHEN** 预览数据超过 1 小时未确认导入
- **THEN** 预览数据失效
  - 需要重新上传文件获取预览

## 数据规格

### 输入

| 字段 | 类型 | 描述 | 必填 | 格式要求 |
|------|------|------|------|---------|
| file | File | Excel 文件 | 是 | .xlsx 格式，≤10MB |
| sheet_name | string | Sheet 名称 | 否 | 默认第一个 sheet |
| header_row | int | 标题行号 | 否 | 默认第 1 行 |
| mapping_rules | object | 字段映射规则 | 否 | 默认使用标准映射 |

### 导入模板字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 用户名 | string | 是 | 3-50字符，字母开头 |
| 密码 | string | 是 | 8-100字符，包含大小写字母和数字 |
| 姓名 | string | 是 | 2-50字符 |
| 工号 | string | 是 | 唯一标识 |
| 邮箱 | string | 否 | 有效邮箱格式 |
| 手机 | string | 否 | 11位手机号 |
| 部门 | string | 是 | 部门名称 |
| 岗位 | string | 否 | 岗位名称 |
| 上级 | string | 否 | 上级姓名 |
| 状态 | string | 否 | 启用/禁用，默认启用 |

### 输出

```typescript
interface ImportPreviewResponse {
  batch_id: string;        // 批次ID
  total_count: number;     // 总行数
  success_count: number;   // 可导入行数
  conflict_count: number;  // 冲突行数
  error_count: number;     // 错误行数
  preview: PreviewRow[];   // 预览数据
  conflicts: ConflictItem[]; // 冲突列表
  errors: ErrorItem[];     // 错误列表
  expires_at: string;      // 过期时间
}
```

## 边界条件

1. **文件大小限制**: 最大 10MB
2. **行数限制**: 最大 1000 行
3. **预览有效期**: 1 小时
4. **并发限制**: 每个用户同时只能有 1 个预览批次

## 错误处理

| 错误码 | 错误信息 | 处理方式 |
|--------|----------|----------|
| IMPORT_001 | 文件格式不支持 | 提示用户使用 .xlsx 格式 |
| IMPORT_002 | 文件大小超限 | 提示用户拆分文件 |
| IMPORT_003 | 行数超限 | 提示用户拆分文件 |
| IMPORT_004 | 必填字段缺失 | 显示缺失字段列表 |
| IMPORT_005 | 数据格式错误 | 显示格式要求 |

## 质量属性

### 性能要求
- 100 行文件解析 < 1秒
- 1000 行文件解析 < 10秒
- 冲突检测 < 3秒

### 安全要求
- 上传文件不执行任何代码
- 文件内容不存储敏感信息明文
- 预览数据按用户隔离
