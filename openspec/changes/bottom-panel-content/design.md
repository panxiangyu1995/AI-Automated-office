# Design: bottom-panel-content

## 上下文

L4 Bottom Panel 用于展示 L3 工作区内容的补充信息，根据当前 Tab 类型动态渲染。

**约束：**

- Bottom Panel 是 L3 内容的补充，不是独立内容区
- 根据当前 Tab 类型显示相关面板
- 支持多种内容类型

## 目标 / 非目标

**目标：**

- 实现 BottomPanel 内容管理器
- 实现多种内容类型
- 与 Tab 系统集成

**非目标：**

- 不实现 Terminal 功能
- 不实现独立的内容区

## 内容类型定义

### 1. PropertiesPanel（属性面板）

显示当前选中元素的属性信息：

```
┌─────────────────────────────────────────────────────────────┐
│ 属性                                                            │
├─────────────────────────────────────────────────────────────┤
│ 文件名      test.pdf                                          │
│ 大小        2.3 MB                                           │
│ 类型        PDF 文档                                          │
│ 创建时间    2024-01-15 10:30                                  │
│ 修改时间    2024-01-20 14:22                                  │
│ 标签        报价单, 重要                                      │
└─────────────────────────────────────────────────────────────┘
```

### 2. DiagnosticsPanel（诊断面板）

显示当前内容的诊断信息：

```
┌─────────────────────────────────────────────────────────────┐
│ 诊断                                                            │
├─────────────────────────────────────────────────────────────┤
│ ⚠️ 缺少必填字段: 客户名称                                      │
│ ⚠️ 金额格式错误: 预期数字，实际为文本                           │
│ ✓ 税率计算正确                                                 │
│ ✓ 日期格式符合要求                                              │
└─────────────────────────────────────────────────────────────┘
```

### 3. PreviewPanel（预览面板）

显示内容预览：

```
┌─────────────────────────────────────────────────────────────┐
│ 预览                                                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  [图片/PDF/文档预览区域]                                       │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 4. AiSuggestionsPanel（AI 建议面板）

显示 AI 提供的建议：

```
┌─────────────────────────────────────────────────────────────┐
│ AI 建议                                                         │
├─────────────────────────────────────────────────────────────┤
│ 💡 建议添加客户联系人信息                                      │
│ 💡 建议使用标准报价单模板                                      │
│ 💡 检测到相关历史报价单，可参考                                │
└─────────────────────────────────────────────────────────────┘
```

## 决策

### Decision 1: 面板内容来源

**选择：** 根据当前 Tab 的 meta 属性决定面板内容

```typescript
interface WorkbenchTab {
  // ...
  panelType?: PanelType  // 当前 Tab 关联的面板类型
  panelData?: PanelData  // 面板数据
}

type PanelType = 'properties' | 'diagnostics' | 'preview' | 'ai-suggestions'
```

**理由：**

- 声明式，易于理解
- 每个 Tab 可以指定自己的面板类型
- 数据与 Tab 绑定

### Decision 2: 面板切换

**选择：** 在 TabBar 右侧添加"面板切换"按钮

```tsx
// TabBar 结构
<TabBar>
  <TabList>...</TabList>
  <PanelSwitcher />  {/* 新增：面板切换按钮 */}
</TabBar>
```

**理由：**

- 符合 VSCode 模式
- 用户可以快速切换面板类型

## 组件结构

```
BottomPanel
├── PanelHeader (面板标题 + 切换按钮)
├── PanelTabs (面板类型切换)
└── PanelContent
    ├── PropertiesPanel
    ├── DiagnosticsPanel
    ├── PreviewPanel
    └── AiSuggestionsPanel
```
