# Specification: 本地硬件设备调用

## 需求来源

### PRD 需求
- **FR6**: 用户可以调用本地硬件设备（扫描仪、打印机等）
- **NFR32**: 支持扫描仪、打印机等标准设备

## 功能规格

### 用户故事
As a 用户,
I want 调用本地硬件设备（扫描仪、打印机等）,
So that 可以在 AI 辅助下完成纸质文档的数字化。

### 验收场景

#### Scenario 1: 扫描文档
- **GIVEN** 用户需要扫描文档
- **WHEN** 在 AI 对话中请求扫描
- **THEN** 列出可用的扫描仪设备
- **AND** 显示设备名称和制造商
- **AND** 选择设备后可设置扫描参数
- **AND** 扫描完成后结果自动导入到对话中

#### Scenario 2: 打印文档
- **GIVEN** 用户需要打印文档
- **WHEN** 在 AI 对话中请求打印
- **THEN** 列出可用的打印机设备
- **AND** 标识默认打印机
- **AND** 可预览打印效果
- **AND** 可设置打印参数（份数、双面等）

## 数据规格

### 扫描仪设备
| 字段 | 类型 | 描述 |
|------|------|------|
| id | string | 设备唯一标识 |
| name | string | 设备名称 |
| manufacturer | string | 制造商 |

### 打印机设备
| 字段 | 类型 | 描述 |
|------|------|------|
| id | string | 设备唯一标识 |
| name | string | 设备名称 |
| isDefault | boolean | 是否为默认打印机 |

### 扫描参数
| 字段 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| resolution | number | 300 | 分辨率 (DPI) |
| colorMode | string | "color" | 颜色模式 |
| pageSize | string | "a4" | 页面大小 |

## 平台支持

| 平台 | 扫描仪 API | 打印机 API |
|------|-----------|-----------|
| Windows | WIA | Win32 Printing |
| macOS | ImageCaptureCore | CUPS |

## 性能要求

| 指标 | 目标值 |
|------|--------|
| 设备枚举时间 | < 2 秒 |
| 扫描响应时间 | 取决于设备和设置 |
| 打印响应时间 | < 1 秒（不含打印过程） |
