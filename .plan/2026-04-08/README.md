## 使用说明

### 选择任务
1. 查看 task.json 中的任务列表
2. 选择 `passes: false` 的任务
3. 检查依赖关系，确保前置任务已完成

### 任务执行流程
1. 阅读任务描述和 steps
2. 检查 `frs_covered` 确认PRD合规
3. 实现功能代码
4. 执行测试验证
5. 更新 task.json 的 `passes` 为 `true`
6. 提交 git commit

### 进度追踪
- 每次会话开始前检查 task.json
- 记录已完成任务到 progress.txt
- 定期更新开发规划文档
