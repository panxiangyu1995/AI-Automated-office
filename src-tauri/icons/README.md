# AI-Automated-office 图标目录

此目录包含应用程序图标文件。

## 需要的图标文件

- `32x32.png` - 32x32 像素 PNG 图标
- `128x128.png` - 128x128 像素 PNG 图标
- `128x128@2x.png` - 256x256 像素 PNG 图标（高 DPI）
- `icon.icns` - macOS 图标文件
- `icon.ico` - Windows 图标文件
- `icon.png` - 系统托盘图标

## 图标生成

可以使用以下工具生成图标：

```bash
# 使用 Tauri 图标生成器
pnpm tauri icon /path/to/source-icon.png
```

## 当前状态

当前使用占位图标。正式发布前需要替换为实际图标。
